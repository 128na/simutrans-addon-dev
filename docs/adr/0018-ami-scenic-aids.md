# ADR: AMI の範囲に景観の補助（盛土の建物の版・説明用の色の way・ラウンドアバウト）を入れる（ADR 0008 の「入れない物」の一部を置き換える）

> ステータス: Accepted (2026-11-27)。[ADR 0008](0008-ami-scope-second-phase.md) の「入れない物」のうち、盛土の building の版・説明用の色つきの way・路面表示のラウンドアバウトを置き換える。0008 のほかの決定は有効
> 由来: [#372](https://github.com/128na/simutrans-addon-dev/issues/372)・管理 [#374](https://github.com/128na/simutrans-addon-dev/issues/374)（第 6 弾）

## 背景と問題

[ADR 0008](0008-ami-scope-second-phase.md) は、次の物を入れなかった。盛土の building の版（`cur` は名所になって乗客の行き先になる）、橋に見せる補助の way（iss は track の高架の way で列車が走る）、説明用の色つきの way（iss の説明のための物）、路面表示のラウンドアバウト。2026-11-26、ユーザーが第 6 弾に「景観の補助」を足すと決めた（判断 70）。

0008 が挙げた理由のうち、盛土の建物は、本体のコードを読むと避けられると分かった。

- `type=cur` の建物は、`passengers=0` にすると、町からの行き先の重みが 0 になる（`dataobj/koord.h` の `weight_by_distance` は 0 以下の値を 0 にする）。乗客を出す側の建物の一覧（町の `buildings`）には、名所の建物は入らない
- `chance=0` にすると、地図の作成などで自動に建たない（`bauer/hausbauer.cc` の `get_random_desc` は重み 0 を選ばない）
- 名所の一覧と地図の表示には出る。プレイヤーが建物の道具で選んで建てる（この作りを決めた時点で、一覧の窓から建てることは未確認。確かめたのはスクリプトで建てることだけ）

## 決定

- 盛土の建物の版を入れる。`type=cur`・`passengers=0`・`chance=0`。直線の 4 向きと外の角の 4 向きの 2 つの物にする（`dims=1,1,4`）。8 向きの 1 物にしないのは、8 layout の名所の建物は地図の回転で向きが崩れるため（本体の `obj/gebaeude.cc` の `rotate_layout`。4 以下は順に回る）。名前は `ami_embankment_building`・`ami_embankment_building_corner`
- 説明用の色の way を入れる。iss の `util/describe` と同じ 4 色 × 地上（`tram_track`）・高架（`track` の `system_type=1`）の 8 物で、速さ 1。名前は `ami_describe_<色>`・`ami_describe_<色>_elev`。色はつながる向きで描き分けられないので、色ごとに物を分ける
- ラウンドアバウトの路面表示を入れる。手本は iss の `util/road_misc/round_about.dat`。3×3 の 1 物 `ami_mark_roundabout`。iss の 4×4（2 物）は作らない
- 橋に見せる補助の way は、この ADR では決めない（作りの判断を [#372](https://github.com/128na/simutrans-addon-dev/issues/372) で別に行う）

## 検討した代替案と却下理由

- 入れないままにする（0008 のとおり） → ユーザーが第 6 弾に入れると決めた
- 盛土の建物を 8 layout の 1 物にする → 地図を回すと向きが入れ替わる
- 盛土の建物の版を iss と同じ 5 種の仕上げ（コンクリートなど）にする → 今の `ami_embankment` の絵（芝）に合わせる。仕上げは足せる
- 説明用の way の高架も `tram_track` にする → iss と issue のとおり `track` にした。速さ 1 なので、線路とつながっても速くは走れない
- ラウンドアバウトの 4×4 も作る → 物が増える。3×3 を確かめてから決める

## 影響・トレードオフ

- 盛土の建物は、名所の一覧に出て、地図の名所の数に数えられる。建てた建物は公共の持ち物になる
- 建物は隣とつながらないので、並べると、隣との境に側面の細い線が見えることがある（way の盛土は隣の向きに合わせて側面を省く）
- 説明用の高架の way は線路の道具の一覧に、地上の way は路面軌道の道具の一覧に出る
- ラウンドアバウトは、一般道路に重ねる路面表示で、路面軌道・線路のタイルには置けない（ほかの路面表示と同じ。ADR 0012）
