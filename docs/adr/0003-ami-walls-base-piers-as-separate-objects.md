# ADR: AMI の壁は way-object、基盤は way の版、橋脚と歩道は別の way にする

> ステータス: Accepted (2026-11-15)
> 由来: [ADR 0002](0002-ami-scope.md)

## 背景と問題

blender-poc は、壁・基盤・橋脚・欄干を way の絵に焼き込んでいた。線路 1 種類に、側壁 4 版・高架 4 版・橋・トンネルの way を持たせた。

- AMI は壁を付ける種類が 5 つ（在来線・高速線・道路 3 種）ある。焼き込むと、種類ごとに 4 版 × 地上・高架の way が要り、絵の数と名前が増える
- 歩道付きの道路に壁・高架を作る穴（POC の C1）が残っていた
- iss は壁を way-object（`way-object/rail`・`way-object/road`）、橋脚と歩道を別の way（`util/pier`・`util/sidewalk`）にしている

## 決定

- **壁**: way-object にして、線路・道路の上に重ねる。版は `single`（両側）・`back`（奥だけ）・`front`（手前だけ）。線路用と道路用で別の way-object にする。地上・高架・橋で同じ way-object を使う
- **線路の壁と架線**: way-object は 1 タイルに waytype ごとに 1 つで、架線も track の way-object なので、壁と架線を別々には置けない。iss と同じく、線路の壁の way-object に架線を持たせた版（電化、`single`・`back`・`center`・`front`。`center` は架線だけ）と、壁だけの版（電化しない、`single`・`back`・`front`）を作る
- 道路の壁は壁だけ。道路の `center` は way-object を置かない
- **基盤**: 線路・道路の way の別の版にする。基盤は壁の位置で止める（POC と同じ見た目）ので、壁の付き方ごとに `single`・`back`・`center`・`front` の 4 版を持つ。壁の way-object と組で使う
- **高架**: 床と床の下の躯体だけを描き、橋脚を描かない。壁の付き方の 4 版を持つ
- **橋脚**: 高架の真下の地面に敷く、別の waytype の way にする（iss の `util/pier/ground` と同じ）
- **橋**: 欄干を描かず、地上と同じ壁の way-object を重ねる。橋の 4 版は作らない
- **歩道**: 道路に描かず、道路の隣のタイルに敷く別の way にする（iss の `util/sidewalk` と同じ）
- 壁・橋脚・歩道は AMI の別の pak にして、AMI の配布に同梱する

## 検討した代替案と却下理由

- POC のまま、壁付きの way を作って pak だけ分ける → 種類が増えるたびに 4 版 × 地上・高架の way が増える。壁の無い way と壁の版を敷き替える手間も残る
- 基盤を壁の way-object に描かせる → way-object には雪の絵のキーが無く（[reference](../reference/way-addon.md) の 10 章）、雪の道床と雪の無い基盤がずれる
- 基盤をタイル全面の 1 版にする → 壁の外に基盤が出る。POC で決めた見た目（壁で止まる）と違う
- 橋脚を高架に重ねる way-object にする → 床の下を地面まで描く絵を、way-object の持ち分で出せるかが分からない。iss は地面の way で作っていて実績がある
- 橋に欄干の 4 版を持たせる → 地上と橋で壁の作りが 2 通りになる

## 影響・トレードオフ

- 線路の壁に架線を持たせるので、架線の作り（柱の位置・高さ、高架・橋・トンネルの中での見え方）も初版の範囲に入る。他のアドオンの架線と AMI の壁は同じタイルに置けない
- way-object は 1 タイルに waytype ごとに 1 つ（tram は track と同じ扱い）。近い斜めの分け合うタイルに back と front の壁を両方は置けない。敷き方と絵は初版で決める（POC の C2 の新しい形）
- way-object には雪の絵が無い。壁は雪で変えない（POC と同じ）ので困らないが、壁の上に雪を描くことはできない
- 使う人は、壁の版の way と壁の way-object を組で敷く。橋脚は高架の下に手で敷く。組を間違えると壁と基盤がずれる
- 橋脚の way は、高架の下のタイルをふさぐ
- 壁の way-object は橋の上の手前の絵（車両より手前）を出せるかを、初版で確かめる。出せなければ、この ADR を見直す
