# ADR: AMI のベータの間は、名前が変わったときのセーブデータの注意を readme に書かず、compat.tab での引き継ぎは正式版以降にする

> ステータス: Accepted (2026-11-21)
> 由来: [#137](https://github.com/128na/simutrans-addon-dev/issues/137)（配布用の readme を絞る）・[ADR 0007](0007-ami-beta-distribution.md)

## 背景と問題

[ADR 0007](0007-ami-beta-distribution.md) は「影響・トレードオフ」で、正式版までに物の名前が変わるとベータの版で作ったセーブデータの物が読み込めなくなることがあるので、readme でそのことを知らせるとした。

#137 で配布用の readme（`addons/ami/release/readme.txt`）を、ユーザーの書いた簡潔な説明・導入方法・注意点に置き換えた。その文面には、この注意が無い。作業者が ADR 0007 との違いを尋ねた。

ユーザーの答え（2026-11-21、進捗管理を通して）: 名前が変わると別のアドオンに置き換わるが、基本的に起動はできる。compat.tab でのフォローは正式版以降にする。

## 決定

- ベータの間は、名前が変わったときのセーブデータの注意を readme に書かない。readme の注意点（「アドオンが増えたり減ったりする場合があります」「設定値は仮です」）で足りるとする
- 名前を変えたときに、古い名前の物を新しい名前へ引き継ぐ `compat.tab` は、正式版以降に用意する

## 検討した代替案と却下理由

- ADR 0007 のとおり readme に注意を書く → ユーザーの文面を正とする（#137）。名前が変わっても起動はできるので、遊ぶ人が困る度合いは小さい
- ベータの間から compat.tab を用意する → 名前がまだ変わる段階で、引き継ぎの表を保つ手間が大きい

## 影響・トレードオフ

- ベータの版で作ったセーブデータは、名前が変わった物が別の物に置き換わって表示されることがある。遊ぶ人は readme の注意点から察する必要がある
- 正式版を出すときに、ベータからの名前の変更を compat.tab にまとめる。再検討のきっかけは、正式版の準備か、ベータの名前の変更で起動できなくなる例が見つかったとき
