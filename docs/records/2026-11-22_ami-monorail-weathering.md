# 作業ログ: モノレールに汚しを付けて、第 1 弾の高架と見分けやすくする（#154）

（2026-11-22）

## 目的 / 発端

跨座式モノレール（#113、PR #153）の確認で、ユーザーから「橋脚とコンクリ軌道の色味が同じなのでウェザリングで差別化できるといいかも」と言われた。第 2 弾の物の全体を対象に、同じ素材の色が並んだときに見分けられるようにする。

## やったこと

- 第 1 弾と第 2 弾を並べる見本 `addons/ami/ingame/weathering_lineup.nut` を足した
  - 11 組を、それぞれ等倍の画面（約 4 タイル四方）に収まる 5 タイル四方に並べた。組は、モノレール（跨座・懸垂の高架、懸垂の地上）×線路・道路の高架と橋脚、車庫、操車場、運河、歩道・柵・電柱、中央分離帯・標識、盛土
  - `sample_parallel.sh` に `NUT` と `SPOTS` を渡して撮った（`addon_check` の写し、ポート 47300〜47303）
- 見分けにくい組を、材質の元の色と画面の値で一覧にした（issue のコメント）
  - 一番は、モノレールの桁（0.60）・柱（0.54）と、第 1 弾の高架の躯体・橋脚（0.56）・壁（0.60）。等倍の画面の明るい面で測ると、橋脚 152、躯体の側面 153、桁の側面 162
  - モノレール自身の桁と柱も、同じまだらで 1 つの塊に見えた
  - ほかの第 2 弾の物は、形か色で見分けられた: 車庫の外壁 0.74、操車場は低い、運河は水面、電柱・標識は細い、盛土は芝、歩道は暗い敷石
- `sheetlib` の `tiled_concrete_material` に、汚しの引数を足した。既定では掛からない
  - `tint`: 色の倍率
  - `streak`: 雨だれ。縦の面に、縦に長い筋を付ける
  - `grime`: 地際の汚れ。高さの範囲の下ほど暗くする
- 案の試作の入口 `addons/ami/blender/weather_calib.py` を足した。跨座・懸垂の高架の center 版だけを、`_w<案>` の名前で描いて `rounds/ami_weather_calib.pak` にした
  - A 色味: 暖かい灰（赤 ×1.04、青 ×0.92）。柱を桁より 8% 暗くする
  - B 雨だれ: 最大 30% 暗くする
  - C 地際の汚れ: 柱の下端（地面より 0.5 単位下）で 45% 暗く、下端から 3.5 単位で 0。地面の高さでは約 39%
- ユーザーが「推奨案で」と答えた（進捗管理のセッション）。決まったこと:
  - 案は A＋C
  - 範囲はモノレール（跨座・懸垂の地上と高架の版）だけ
  - 第 1 弾の色は変えない
- 決まった案を `sheetlib/monorail_parts.py` の `mono_concrete` に入れた
  - 桁・柱のまだらを、`track_noise`（タイルの辺で周期にならない 2 色のまだら）から `tiled_concrete_material` に替えた。振れ幅と粒は前と同じ
  - 柱の地際の汚れの高さは、柱の下端（`post_bot`。高架の版は高架の段の分だけ下）から測る。懸垂式は地上と高架で材質を分けた
- モノレールの 10 シート（跨座の地上 1・高架 3、懸垂の地上 3・高架 3）と、跨座式のトンネルのシートを `render_parallel.py` で描き直した。跨座式の地上のシートの絵から作るトンネルのアイコンは、`icons.py` で作り直した
- 直す前と直した後を、同じ見本・同じ場所・等倍で、温暖と降雪の両方とも撮った（`addons/ami/docs/weather_before_after_*.png`）

## 分かったこと・つまずき

- `import sheetlib.monorail_parts as MP` は、モジュールではなく関数 `monorail_parts` を返した。`sheetlib/__init__.py` が同じ名前の関数を出しているため。試作で材質の定数を差し替えたつもりが効かず、最初の案の絵は今の版と同じだった。`sys.modules["sheetlib.monorail_parts"]` から引いて直した
- Squirrel では `base` が予約語で、変数の名前に使うとコンパイルが通らなかった（「Error compiling string buffer」）
- `way_desc_x` などは、無い名前でも null を返さない。`is_valid()` で確かめる（本体 `script/api/api_obj_desc.cc` の `export_is_valid`）
- 雨だれの案（B）は、等倍では細かいざらつきに見え、タイルの継ぎ目で筋が切れて見える所があった。採らなかった
