# 調査/作業ログ: AMI のコミット済みシートと今の描画のずれの総点検（#229）

## 目的 / 発端

#223（PR #228）の作業者が、`addons/ami/src/ami_wall_rail_old_back.png` が今の描画と違うと見つけた（2026-11-24）。第 3 弾（景観、#172）のリリースの前に、配る pak の絵が今の描画とそろっているかを確かめる。

## 分かったこと（事実）

- 方法: main（d4bb626）で、AMI の全 211 対象を `render_parallel.py`（Blender 4.5.16）で `src/` に描き直し（踏切 7 対象は道路の後）、そのあとアイコン・カーソルの後処理（`blender/icons.py`、全部）を流して、コミット済みの PNG と比べた。
- **`ami_wall_rail_old_back.png` を含む線路の壁 8 枚（`ami_wall_rail_*`・`ami_wall_rail_old_*` の back・center・front・single）は、描画のずれではなかった。** 壁のシートは基盤の対象（`ami_rail_ballast_base_*`、旧は `ami_rail_ballast_old_base_*`）が書く。`render_parallel.py` は `render.py` を `--own` で呼ぶので、アイコン・カーソルのセルを書かない。このため、描き直しただけだとアイコンのセルが「W」の仮の絵になり、コミット済み（漢字の札のアイコン）と違って見える。アイコンの後処理を流すと、8 枚ともバイトまで一致した。#223 の作業者が見たずれは、この後処理が抜けた比べ方によるもの。
- 後処理まで流しても残ったずれは 5 枚。どれもアイコン・カーソルのセルだけで、タイルの絵は変わらない（差分の範囲が小さな 1〜数セルに収まる）。
  - `ami_mark_junction2_t.png`: コミット済みのアイコンの札が「流」（`ami_mark_merge_ramp` の札）。今は正しく「丁」。
  - `ami_mark_merge_main.png`: コミット済みは札が無い。今は「合」。
  - `ami_monorail_suspended_elev_center.png`: 札の字が崩れている（コミット済み）。今は「150中」。
  - `ami_sign_crosswalk_one_way.png`: コミット済みの札が「後」。#201（db1bff4）で一方通行のアイコンの元を `image[1]` に変えたのに、シートを描き直していなかった。今は「単」。
  - `ami_road_local_base_single.png`: アイコンの下地の色味がわずかに違う。
  - 前後の切り抜きは `addons/ami/docs/229_icon_drift/`。
- 描画は決定的。ただし、`ami_rail_concrete_elev_single`・`ami_rail_concrete_old_elev_front`・`ami_rail_ladder_elev_back` は、全対象を 1 回で並列に描いた回だけコミット済みと違い、単独で描き直すと一致した（その 2 回目と 3 回目は同じ）。描いている最中の別のシートを読んだ順番の違いと見られる（原因は未確認）。全部描くときは、結果が違ったシートだけを単独で描き直して確かめる。
- アイコンの後処理を 2 回続けて流しても、結果は変わらない。

## 推測・未確認事項

- 「札が違う」4 枚（mark 2 枚・suspended_elev_center・crosswalk_one_way）が、コミットした時点でなぜ違ったかは、crosswalk_one_way 以外は特定していない。アイコンの後処理を、描いたシートが全部そろう前に流した（並列の描画の途中）ことが疑わしい。
- 高架 3 枚の初回の差の原因（上のとおり）。

## 結果どうしたか

- 後処理まで流した 5 枚の PNG を描き直してコミットした（#229）。pak は `build.py` で作れた（警告なし）。
- 影響はアイコン・カーソルのセルだけで、ゲームの map の見た目は変わらない。確認はアイコンの前後の切り抜きで行った（ゲームのタイルの前後の画像は、タイルが変わらないので撮っていない）。
- 手順への申し送り: 「全シートを描き直して比べる」ときは、描いた後に `icons.py`（全部）まで流してから比べる。AMI の README にこの手順が無いなら足す（作業者は直さず、進捗管理へ）。
