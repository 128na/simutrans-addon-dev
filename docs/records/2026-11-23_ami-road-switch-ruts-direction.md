# 作業ログ: AMI の道路の T字の 1・2 の轍の向きを、線路と同じ向きに改める（#46）

（2026-11-23）

## 目的 / 発端

#46 で道路の分岐の絵を dat に戻し、OTRP v64 で確かめたところ、ユーザーが区画 M（枝の隣がカーブの T字）の画像で指摘した: 「M.png の轍の跡が逆向き。180 度ターンして合流する向きになっている」。

## 原因

2026-11-19 のユーザーの指定（[2026-11-19_ami-road-switch-ruts](2026-11-19_ami-road-switch-ruts.md)）で、道路の轍は「枝と、固定の道具の名前の反対側の本線の端」をつなぐ向き（線路と逆）に描いていた。v64 の自動選択は、枝の隣がカーブの T字に「1」を出す。区画 M（本線が南北で、東へ出た枝がすぐ南へ折れる）では nse1 が出て、轍が枝から南の端へつながり、北から来て南へ戻る 180 度ターンになった。

## 直したこと（2026-11-23、ユーザーの決定: 轍の向きは線路にそろえる）

`tools/blender/sheetlib/road_parts.py` の `SWITCH_RUT_ARCS` を、1・2 の組ごとに入れ替えた。轍のカーブは、枝と名前の側の本線の端をつなぐ（線路と同じ。reference 9.2）。

| 絵 | カーブ（前 → 今） |
|---|---|
| `nse1` / `nse2` | 東–南 → 北–東 / 北–東 → 東–南 |
| `new1` / `new2` | 北–西 → 北–東 / 北–東 → 北–西 |
| `nsw1` / `nsw2` | 西–北 → 南–西 / 南–西 → 西–北 |
| `sew1` / `sew2` | 南–東 → 南–西 / 南–西 → 南–東 |

道路 3 種の通常の版・基盤 4 版・高架 4 版の 27 枚のシートを `render_parallel.py` で描き直した（145 秒）。`tools/blender/sheet_diff.py` で前後を比べると、透過の範囲の差は 0、色が変わったセルは分岐のセル（行 2・3・6・7 の列 10〜13）だけ。ほかに、`ami_road_expressway_base_single` と `ami_road_local_base_single` の先頭の 1〜2 セルに 45〜48 画素の色の差が出た（原因は未確認。描画の揺らぎか、前の描き直しの残り）。dat は変わらない。

## 確かめたこと

v64（`sim-WinGDI64-OTRPv64.exe`）、`flat_512_left_v64.sve`、`road_sample.nut` の区画 M・M2（M2 は nsw で、西へ出た枝が北へ折れる形。新しく足した）。自動選択はどちらも「1」で、轍は来た向きのまま本線へ合流する向きになった（画像 `addons/ami/docs/road46_v64_GE_M_M2_zoom.png`、左が M、右が M2）。左側通行の地図だけ。カーブが逆向きの T字（「2」が選ばれる形）は撮っていない。
