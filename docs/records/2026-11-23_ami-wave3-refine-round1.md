# 作業ログ: 第 3 弾の物の精細化のラウンド 1（路面表示・運河、#197）

（2026-11-23）

## 目的 / 発端

#197 に、ユーザーの言葉「このフェーズは高精細化も含んでいるはず。鉄道でやった時と同じ。手順化されているはず」で、精細化のラウンド（スキル `way-refine-rounds`）を足した。土台は PR #214（汚し A〜C）の本番の絵。系統 `wave3`（`AMI_FAMILY=wave3`。`blender/round_wave3.py`、`round.py` の `FAMILIES`）を足した。対象は路面表示（`ami_mark_*`）と運河・景観の運河。運河の踏切は運河のセルが下地なので入れない。

## 準備

- 空のラウンド（`0null`）で `ami_mark_lane4`・`junction4_in`・`lane6_m`・`ami_canal`・`ami_canal_scenic` を描き、今の `src/` と画素で同じことを確かめた（PNG のバイトは違うが、画素の差は無い）
- ラウンド 0 の pak（`rounds/ami_wave3_round0.pak`）とラウンド 1 の pak（`ami_wave3_round1.pak`）を作った

## 葉ごとの試し（セルで 4 倍。画像 `addons/ami/docs/197_rounds/r1_chip.png`・`r1_canal.png`）

| 鍵 | 中身 | 判断 |
|---|---|---|
| 1chip | 白線の 2 色の段の下端を路面の色にし、欠けを出す（段 0.43） | 矢印・縞に欠けが出るが、1px の路側線が点々に切れる。弱めた 1chip2（0.41）を採る |
| 1rip | さざ波の縞の Scale 14 → 8、ゆがみ 2.0 | 不規則な波になったが、PR #214 でさざ波の変更を取り下げた（交差点と直線で波が連続しない。ユーザーの指摘、2026-11-23）ので採らない。作り直したラウンドからも外した |
| 1wl | 護岸の水際の染み（高さ 0.7、強さ 0.75） | 弱い。採らない |
| 1wl2 | 染みの高さ 1.2、強さ 1.0、色を濃く | 壁面の白が水際で落ち着き、運河の水と壁がなじむ。採る |

## ラウンドの版

`ROUND_SETTINGS["1"]` = 1wl2 + 1chip2（作り直し。1rip は外した。土台は PR #214 の最新の絵）。`rounds/ami_wave3_round1.pak`。

## 評価（今の本番と比べて）

| 観点 | 判定 | 理由 |
|---|---|---|
| ① 欠陥 | 同じ | 景観の運河の斜めの内壁の細い横線は残っている（形の問題）。新しい欠けは見えなかった。`sheet_audit.py` は流していない |
| ② 写実 | 良くなった | 景観の運河の壁に水際の染み（暗い帯。高さの座標なのでタイルをまたいで連続）が出て、白い壁が水面になじんだ。白線に塗料の欠け |
| ③ くどさ | 少し増えた | 物差しで測っていない（`busy_measure.py` は流していない）。見た目では水面の縞が粗くなった分、目立つ |
| ④ そろい | 同じ | 路面表示は 1chip2 を全種類に掛けるので、下の道路の白線（一色）との差が少し広がる |

画像: `addons/ami/docs/197_rounds/r1_game_canal.png`（上から 景観の運河 温暖・降雪・斜め。左が今、右がラウンド 1。拡大率 3。v64・`ami_catalog.sve`。景観の運河 (37,625)・降雪 (549,625) など、`canal.nut` を原点 (30,620) に敷いた物と、y に +60 したラウンド 1 の名前の物。降雪側は x+512）。斜め（下段）の細い横線は、ラウンド 1 でも残っている（形の問題。#197 の 2）。

## 判断できない点

- 路面表示のラウンド 1 は、ゲームの中で隣の道路と組み合わせて撮っていない（見本の nut がラウンドの名前を引けない）。セルの比べだけ
- 道路の分岐（#46・#205）の降雪の境、景観の運河の細い横線は、構造の試しをしていない（共通の `road_parts.py` を変える必要があり、進捗管理がユーザーに扱いを聞いている）
- 路面の板（舗装）の走行跡と、横断歩道と停止線（#162）の標識の絵も、このラウンドでは試していない

## 本番に入れるとき

`round_wave3.py` の `apply` が差し替えている物（`render.MARKING_LINE_WORN`、`canal._materials`）を、`render.py` と `canal.py` の値・引数に写す。景観の運河の壁の材質は `canal.py` の `_materials` に水際の染みの口を足す。

## 本番に入れた結果（2026-11-24）

1wl2 は PR #218 で本番に入れた。1chip2 は、ユーザーの決定で入れていない（1px の路側線が点々に切れるため）。1rip（さざ波）は PR #214 で取り下げた。「本番に入れるとき」の節の写し方は、1wl2 では `canal.py` の `SCENIC_STYLE` の `waterline` と `_waterline_wall` に写した。
