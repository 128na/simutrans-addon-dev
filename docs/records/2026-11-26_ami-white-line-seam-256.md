# 作業ログ: 256 で白線が向きを変える継ぎ目が欠ける（#354）

## 目的 / 発端

pak256 で AMI の 256 版 alpha.7（3658e5c。#333 の PR #340）を確かめると、白線が向きを変える所の継ぎ目が崩れていた（pak256 の [#134 の記録](https://github.com/128-bit-net/pak256/blob/62078f703afe6e662c1599c2880b9e095707517b/docs/records/2026-11-26_ami333.md)。pak256 の判断 54 で AMI に依頼）。

- 横の線が斜めに変わる所（2 段の台の十字、橋の面と端の坂の境）: 横の線の端が横 3px 欠ける。
- 斜めの線が縦の線に変わる所（道路の斜め、高架の曲がり）: 斜めの線の先が欠け、縦の線の上に 1px が飛び出す。
- alpha.6 には無い。

## 分かったこと（事実）

- #340 の案 A は、256 で道路の位置（`ROAD_CY`）で描く物を、平らでも地面の位置まで塗る（`cells._ground_mask_direct`）。平らなタイルの奥の 2 辺の上に、2 行の帯が増えた。
- 道路は絵全体を地面より 2 行下げて描く。そのため帯の画素は、自分のタイルの外（奥の隣のタイルの手前の端にあたる所）を描いた絵になっている。奥の隣が同じ道路なら、その帯は奥のタイルの道路の菱形の中で、奥のタイルが自分の本当の絵で埋める。
- ゲームは奥のタイルから描くので、手前のタイルが帯を塗ると、奥のタイルの本当の絵を、手前のタイルの絵の延長で覆う。
  - まっすぐ続く所では、延長と本当の絵が同じ（路面の粒だけが違う）。
  - 白線が向きを変える所では、延長した線が奥の線と食い違い、欠けと飛び出しになる。alpha.6 は帯を塗らず、奥の絵が見えていた。
- 帯が要るのは、奥の隣が道路でない辺（先が草）だけ。坂と平らの境で奥の縁が跳ぶのを防ぐため（#333）。
- 256 のシートを重ねて確かめた（ゲームと同じく奥から重ねる）。
  - 2 段の坂の奥に平らな直線、直線の奥に斜め（3 枚目の斜めのタイルまで）の組で、main の絵に飛び出しと段が出た。直した絵は alpha.6 と同じ線の形になった。
  - 斜めのタイルは菱形の半分の絵なので、2 枚だけ重ねると、つながる西の辺の上に段が見えた。3 枚目（西の隣の斜め）を重ねると、その帯を埋めて段は消えた。ゲームの斜めの道でも段は無い（下）。

## 推測・未確認事項

- 雪の気候の白線は、前後で形が同じ向きに変わったのを 2 段の坂の 1 か所で見ただけ。
- 路面軌道・運河・歩道・踏切の踏板（道路の位置で描く物）は、256 の絵を組まずに撮ったので見ていない。マスクは同じ経路で、つながる辺の帯を空ける。
- つながる辺の先が、同じ道路でない物（つながる別の way・車庫など）の所は見ていない。その物が帯を埋めなければ、alpha.6 と同じく奥の縁が 2 行下がって見える。
- 256 の #360（雪の道路の base の下の端の暗い点線）には響かない見込み。今回変えたのは平らなタイルの奥の 2 辺の上だけで、手前の縁（下の端）は変えていない。確かめてはいない。

## 結果どうしたか

- `cells._ground_mask_direct` に、タイルのつながる辺（`exits`）を渡す引数を足した。`render_cell` が持ち分の絵を書くとき（`_render_ground`）に渡す。平らなタイルで、つながる奥の辺（北 = 右の半分の列、西 = 左の半分の列）の上の帯を空ける。坂・つながらない辺・`exits` を渡さない呼び出し（橋脚・踏板など）は前のまま。pak128 の `_ground_mask_1x` は変えていない。
- `tools/blender/check_ground_mask.py` に、平らな道路がつながる辺の上の帯を空け、つながらない辺の上を塗るかの検査を足した。直しを止めると 4 件落ちる。
- 確かめた環境: OTRP v64（`addon_check` の写し）、`flat_512_left_v64`、昼、拡大 3。地面は pak256 の main を `tools/build.py --no-ami` で組んだ物。AMI は 256 の生活道路（本体・橋・高架）と線路（バラスト）と、`src256/` にある物だけを組んで入れた。見本は pak256 の #134 の `scene.py`（256 の絵の無い物は敷かずに飛ばした写し）。前 = main（直す前）、後 = 直した後で、同じ地面と見本。
  - [issue の 6 か所](../../addons/ami/docs/354_white_line_seam/white_line.png)（pak256 の画像と同じ座標。左が前、右が後）: どれも線がなめらかにつながり、alpha.6 と同じ形になった。
  - [#333 で直した所](../../addons/ami/docs/354_white_line_seam/no_regression.png)（台の上の十字の奥の角、1 段・2 段の坂の継ぎ目、T 字の奥の縁、2 段の橋の端、停留所の奥）: 前後で同じ。
  - [タイルの境](../../addons/ami/docs/354_white_line_seam/tile_border.png): 前後で違う画素は、つながる道路のタイルどうしの境の行だけ（46 枚の画面で数えた。ほかは画面の下の帯の時計など）。路面の粒が入れ替わっただけで、見分けが付かない。
- 128 は、道路のシート 6 枚（生活道路・一般道路の本体・橋・高架）を前後で描き、PNG がバイトで同じ。256 の生活道路のシートを描き直した。
