# 調査/作業ログ: 道路のカーブを速さで描き分ける（一般道路は円弧、生活道路は L 字。#259）

## 目的 / 発端

#209 の 2 本目。高速道路・幹線道路は斜めの絵のまま、一般道路（`ami_road_general`）のカーブを円弧、生活道路（`ami_road_local`）のカーブを L 字にする。範囲は地上の通常の版（壁・基盤・高架は 3 本目の #260）。

## 分かったこと（事実）

- 道路 3 種は `expressway`（歩道なし）のプロファイルで描いており、`road_sheet` がカーブのセル（行 2 の列 5〜8）を消して、dat の `image[sw]` などを `diagonal` のセルへ向けていた。円弧のセルは、歩道つきの道路用のジョブ表（blender-poc の街路）にすでにあった（路面軌道と同じ `arc_sw` など）。
- 円弧は、タイルの角を中心に半径がタイルの半分（2 辺の中点をつなぐ）。白線は経路から ±EDGE_LINE なので、辺の中点で直線と同じ位置を通る（直線・T字・十字とのつなぎ目は、白線の位置が同じ）。
- L 字は 3 点の折れ線（辺の中点 → 中心 → 辺の中点）。`sweep` は角の前後の向きの平均で断面を向けるので、90° の角では横幅が 1/√2 に細る。白線・走行跡・路肩の雪の型は、どれも経路を `sweep` で押し出すので、角で細って辺に届かない。そこで `core.MiterPath`（`sweep` が角で断面の幅を保つ経路）を足し、L 字の経路だけに使った（ふつうの経路は今までどおり）。
- `curve` というプロファイルのキーを、一般・生活道路の通常の版だけに持たせた。壁・基盤・高架・橋・トンネルのプロファイルは、通常の版の辞書を写して作るので、写した側は `curve=None` に戻した。
- 橋（`_bridge`）はセルが直線と坂だけ（`BRIDGE_CELLS`）、トンネル（`_tunnel`）は坑口の 4 向きだけで、カーブのセルが無い。本体は橋・トンネルの中を曲げないので、この issue の「橋・トンネルのカーブ」は変えるものが無かった。両方のシートは描き直しても 1 画素も変わらない。
- 描き直して変わったのは `ami_road_general`・`ami_road_local` のカーブのセル（夏・雪の 4 + 4 セル）と dat（`image[sw]` などの 8 行）だけ。次の物は描き直して、コミット済みの絵と 1 画素も違わなかった（ベースラインは、変更前のコードで描いた絵がコミット済みと一致することを先に確かめた）: `ami_road_expressway`・`ami_road_general_base_single`・`ami_road_local_elev_front`・`ami_road_general_bridge`・`ami_road_general_tunnel`・`ami_wall_road_single`・`ami_wall_road_front`。
- ゲーム（`OTRPv64`、`flat_512_left_v64.sve`、温暖 (20,20) と降雪 (276,20)）で、輪（カーブ 4 向き）・2 本並べた輪・坂の隣・T字の隣・隣り合う直線・斜め・pak128 標準の道路とのつなぎ目・路面軌道を重ねた輪・路面表示（`ami_mark_*`）の十字を撮って見た。2 本並べた輪（4 車線の直角の曲がり）は、前の斜めの絵では内側の線と外側の線のカーブのタイルの間に草の三角が出ていたが、円弧・L 字では出ない（画像は `addons/ami/docs/259_road_curves/`）。
- 路面軌道を重ねたとき: 一般道路の円弧は、路面軌道の曲線と同じ中心・半径で重なる。生活道路の L 字は、路面軌道の曲線が L 字の角を内側で切る（崩れてはいない）。

## 推測・未確認事項

- 壁の way-object（`ami_wall_road_<版>`）・基盤・高架の版は、カーブが斜めの形のまま。円弧・L 字の通常の版と重ねると壁・基盤のカーブが合わない。3 本目の #260 で、カーブと壁をそろえる。
- 坂の上の曲がり（坂のタイルがカーブに接する）は、坂の隣を撮って崩れないことを見たが、急坂（2 段）のすぐ隣は撮っていない。
- 右側通行の地図・夜の見え方は見ていない。

## 結果どうしたか

- `tools/blender/sheetlib` の `core.py`（`MiterPath`）・`sheetlib.py`（`road_sheet` の `curve`）、`addons/ami/blender` の `catalog.py`（`ROAD_CURVE_SHAPES`・`DIAG_CURVE_WAYS`）・`render.py`、dat とシートを直した。見本は `addons/ami/ingame/curve_sample.nut`（`sample_spots.sh` の `CURVE_SPOTS`）。README の「道路の作り」のカーブを書き直した。
