# 作業ログ: AMI の道路 3 種の通常の way（#21）

（2026-11-19）

## 目的 / 発端

issue #21。AMI に生活道路（40 km/h、中央線なし）・一般道路（120 km/h、白の実線）・高速道路（360 km/h、白の破線）の通常の版の way を足す。断面は blender-poc の高速道路にそろえる。

## 分かったこと（事実）

- OTRP は道路の T字・十字にも switch 画像を使う。`OTRP-KUTAv6` の `boden/wege/weg.cc` の `calc_image`（732〜739 行）が、`road_wt` で `select_switch_road_image`（988 行〜）を呼ぶ。固定の道具 `tool_set_switch_image` は `feature/switch-image-override` の版だけにあり（`simtool.cc` 12093 行、`weg.cc` の `can_fix_switch_image`・`apply_switch_image_override`）、waytype を問わない
- 道路の自動選択で switch 画像（dat の「1」）になるのは、T字の枝の隣が三方分岐で、本線の両隣が三方分岐でないとき。2 本の道路を隣り合わせに並べて渡り口でつなぐ形で出る
- 固定の道具の選択 1 は dat の「2」（`nw` = true）、選択 2 は dat の「1」（`nw` = false）になる
- 手本のカーブ: iss の道路（`refs/iss/src/way/road/ground.dat`）は、`iss_wrg_0030`・`0050`・`0120_*` の `image[ne]` が曲線のセル（38・83・128・173 行など）で、`iss_wrg_1200_*` は `diagonal` と同じセル（353 行など）。pak128 の `road_030.dat`（`refs/pak128/infrastructure/roads/`）は `Image[NE]=2.4`（カーブ専用の絵）と `Diagonal` の `3.0` が別（33・37 行）
- blender-poc の道路のシート 12 枚は、`build_road` と `tunnel_sheet` に profile を渡せるようにした後に描き直しても、変更前と同じバイト列だった。AMI の在来線・高速線・トンネルのシートも同じ
- 画面で横向きの急坂では、1px の白線（路肩の線・中央線・破線）が灰色に薄く見える。blender-poc の高速道路でも同じで、今回の変更で起きたものではない

## 判断したこと

- カーブは斜めの絵にした（線路と同じ）。#22 の道路の壁を線路と同じ共有の way-object にするには、カーブの形が 1 つに決まっている必要があるため。iss のカーブの絵は取り入れなかった
- 路面の色は、生活道路・一般道路は blender-poc の街路の灰色、高速道路は blender-poc の高速道路の暗い色（`road_parts` の `EXPWY_ASPHALT`）。生活道路・一般道路は pak128 標準の道路とつなぐことが多いので灰色、高速道路は一般の道路と見分けられる色にした
- 中央線の破線は、タイルに固定した刻みにした（`sheetlib/core.py` の `tile_dashes`）。直線はタイルを 4 等分、斜めは 3 等分し、タイルの境が間（すき間）の真ん中に来る。直線と斜め・坂の継ぎ目で途切れない
- 分岐の絵: T字の「1」は分岐しない側の路肩の線と中央線、「2」は路肩の線だけ。十字の「1」は南北の中央線と南北の破線の路肩、「2」は線なし。生活道路は中央線が無いので 1・2 が同じ絵になる
- 見本は線路の `sample.nut` に足さず、`ingame/road_sample.nut` に分けた（コマンドラインの長さの上限に近いため）。撮る場所は `sample_spots.sh` の `ROAD_SPOTS`

## 確かめたこと

- `SHEET_LAYOUT=1` のシートで作った pak で `road_sample.nut` を温暖側・降雪側に敷き、78 枚撮って配置と継ぎ目を見てから塗った
- 通常の pak でも 78 枚撮った（`OTRPv64_3.exe`、`flat_512.sve`、`sample_parallel.sh`）
- `[check]` の行: 近い斜めは 3 種とも `two_ways=false`。区画 H の自動選択は一般道路・高速道路で `auto == pin1 != plain`（`ok`）、生活道路は `same12`（1・2 が同じ絵なので期待どおり）。固定の道具は 3 種とも働いた
- `sheet_audit` は道路のシートで指摘なし。`python -X utf8 build.py` は警告なし（`ami.pak` 37 dat、`ami_road.pak` 3 dat）

## 点検と直しの回数

- 絵の点検→直しは 0 回（最初の塗りで、目立つ欠け・ずれは見つからなかった）
- 見本の検査の条件を 1 回直した: 生活道路で「固定の 1 と 2 が違う」を求めて NG になったので、`ok` を「自動選択が固定の 1 と同じで、通常の T字と違う」にし、1・2 が同じことは `same12` として別に出すようにした
- `sample_parallel.sh` が、全部敷けたときに `[check]` の行を出していなかったので、1 台目の報告を常に出すようにした
