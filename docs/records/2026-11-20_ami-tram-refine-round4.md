# 作業ログ: 路面軌道の精細化のラウンド 4（画面で横向きの斜めのレール、#56）

（2026-11-20）

## 目的 / 発端

ラウンド 3（`2026-11-20_ami-tram-refine-round3.md`）の後、セルを向きごとに並べて見ると、画面で横向きの斜め（`diag_nw`・`diag_se` と、近い斜めの `close1`）で、レールの線が見えなかった（本番の `src/ami_tram.png` から同じ）。縦向きの斜め・直線・曲線では見える。曲線（`curve_nw`・`curve_se`）の中ほど（向きが横向きの斜めになる所）でも線が薄れた。

## 原因

横向きの斜めでは、経路に直角な向きが画面の縦になる。画面の縦は 1 単位が約 4.5px で、直線・縦向きの斜めの横（約 9px）の半分しかない。頭（0.14）と溝（0.14）はどちらも 1px に満たず、セルの縦の切り口で 160・140・140・168 と、床（157〜158）と混ざった。

## 葉ごとの試し

## 本番に入れるときに直す所

- レールの頭の材質（金属 0・明るい色）・寸法、溝の幅、外側の目地なし、縁の帯の色、油の帯なし: `tools/blender/sheetlib/tram_parts.py` の値（`_M_TRAM_RAIL`・`TRAM_GROOVE_W`・`TRAM_SEAM_W`・`TRAM_EDGE_RGB`）か、`blender/render.py` の路面軌道の描き分けで差し替える。路面軌道の部品はほかの系統が使っていないことを確かめる
- T字の穴埋め（`gore`）: 今は組み立て（`sheetlib.sheetlib` の `assemble`）を包んでセルの経路を得ている。本番では、`track_sheet` の T字・十字で、在来線の `bed_fills`（直線と斜めの層のすき間を凸包で埋める）と同じように、セルの経路を受ける口を作る
- 横向きの斜めの幅（`hdiag`）: 点ごとに断面を変える押し出し（`var_sweep`）を `core` に足すか、`tram_parts` の形の関数に向きの倍率を持たせる。同じ欠けが在来線・スラブ軌道のレールにもあるかは見ていない（在来線のラウンド 7 では、斜めのセルで頭の帯が逆に太く出た）
- 本番の絵を描いた後、ラウンド 4 のシートと画素で比べ、ゲームの見本（94 画面）を撮り直す
