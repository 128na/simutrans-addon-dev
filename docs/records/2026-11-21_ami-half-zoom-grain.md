## 分かったこと（事実）

### 本体の縮小

- 1/2 の画面の絵は、等倍の絵の 2×2 の単純平均。透明な画素は平均に入れない（`rezoom_img` の `zoom_den == 2` の分岐）
- 区切りは、画像の基準位置（dat の位置合わせを足した原点）の偶数の座標にそろう
  - 例: `x_rem = base_x % 2` だけ余白を足して読むので、偶奇によらず原点から偶数の座標で区切られる
  - AMI のセル（256px、位置合わせ -64,-32）も pak128 のセル（128px、0,0）も、セルの原点から 2×2 で平均すればゲームの絵になる
- 区切りを 1px ずらすと、孤立点は大きく変わる
  - #79 の在来線の等倍の画面を 2×2 で平均すると、ずらし方 4 通りで 47〜69
  - シートの直線のセルでは 2〜125
- ゲームの値と合うのは、セルの原点にそろえた区切りだけ
  - 例: ラダーの直線は、その区切りで 70/53、ずらすと 0/5。ゲームは 48

### 粒の元（直線のセル。斜めのセルの孤立点は、どの線路も 0）

| 線路 | 元 | 平らにした試し（1/2 の孤立点、南北/東西） |
|---|---|---|
| 在来線・直結軌道 | まくらぎの間隔（タイル 1 辺に 18 本 = 画面で約 3.56px おき）が 2×2 の格子とずれて、うなり（むらのある粒）になる | まくらぎを砕石の色にすると 68/45 → 21/18（等倍の細かさも 0.073 → 0.044 に下がる） |
| スラブ | 締結装置の並び（タイルに 16 組、辺から半ピッチ） | 締結装置を除くと 169/56 → 43/16 |
| ラダー | 梁の間の暗い帯（1/2 で約 1.65px 幅）の縁が、1 画素ごとに明暗に割れる | — |

- レールの頭の明るい帯を側面と同じ色にしても、砕石のまだらを平らにしても、1/2 の値はほとんど変わらなかった
- まくらぎの間隔を 16 本にすると、画面で 4px おきになり、どのまくらぎも同じ形に描かれる。1/2 の値は、位置（`SLEEPER_FIRST`）で大きく変わった
  - 8 通りのずらしを試した。辺から半ピッチ（今までの位置）だと南北が 91 と悪い
  - 辺の上（`PATH_EXT % SLEEPER_PITCH`）は、南北・東西とも 4 以下。向きを逆にした経路でも同じ位置になるので、これにした
- 規則正しいまくらぎは、1/2 で 1 つおきの点線になる
  - `busy_measure.py` はこれを線として除く。線を除く値は下がるが、線を含めて数えると在来線では増える（下の表）
  - 不規則な粒が、規則正しい模様に変わったということ。見た目はユーザーが比べて決めた

### 案ごとの値（ゲーム、温暖。線を除く「細かさ / 孤立点」、( ) は線を含む孤立点）

| 線路 | 直し | 等倍 前 → 後 | 1/2 前 → 後 |
|---|---|---|---|
| 在来線 | まくらぎ 16 本・辺の上 | 0.0722/22.7 → 0.0691/28.3 | 49.5 (56) → 15.2 (72) |
| 直結軌道 | 同上（在来線の部品を使う） | 0.0649/19.4 → 0.0624/15.1 | 36.6 (46) → 6.6 (13) |
| ラダー | 梁の内側の縁 0.23 → 0.30（梁の間が約 4.3px、1/2 でほぼ 2px） | 0.0450/19.8 → 0.0467/9.5 | 47.6 (57) → 17.8 (21) |
| スラブ | 直線だけ、締結装置をタイルの辺の上から置き、横幅 0.34 → 0.26 | 0.0596/30.6 → 0.0577/17.8 | 68.5 (109) → 20.5 (65) |
| 手本 pak128 / SIS | — | 0.0614/60.1・0.0633/15.3 | 16.5 (47)・16.7 (65) |

- 等倍の値は、どれも 11 章の「許容」に入ったまま
  - スラブの細かさ 0.0577 は、下の境 0.058 をわずかに下回る。孤立点 17.8 があるので「許容」
  - ラダーの細かさは、もとから下の境より下にある
- 3/4 の画面の孤立点も下がった（在来線 33.8 → 20.2、直結軌道 27.6 → 16.9、ラダー 9.9 → 6.8、スラブ 13.9 → 6.8）
- 降雪の 1/2（線を除く）: 在来線・直結軌道 13.8 → 8.3、ラダー 10.6 → 10.3、スラブ 18.5 → 17.1
- 試した案のうち、入れなかったもの（どれも、ゲームか描いたシートで値を測った）
  - 在来線 B（18 本のまま、まくらぎの明暗を 25% 弱める）: 1/2 で 29.9、等倍で 0.0637/15.0
  - まくらぎ 14 本・20 本（位置は辺から半ピッチ。シートの直線のセルの値で、南北/東西）: 14 本は 1/2 で 109/67 と増えた。20 本は 36/8 で、南北が下がりきらなかった
  - スラブの締結装置を辺の上に置く変更を、斜め・カーブにも当てた版: 斜めのセルの 1/2 の孤立点が 42〜50 → 150〜167 に増え、等倍の締結装置が見えにくくなった。そのため直線だけにした
- シート全体（`half_measure.py`。セルの 1/2 の画素で重みを付けた合計。線を除く → 線を含む）
  - 在来線: 20.4 → 14.7、37.5 → 43.1
  - 直結軌道: 15.3 → 11.2、32.8 → 31.0
  - ラダー: 13.9 → 6.3、30.6 → 22.2
  - スラブ: 27.4 → 10.8、57.1 → 40.6
  - 在来線・直結軌道は、坂（セル 1.2・1.3）・斜め 1 つ・1 タイルだけの絵・雪のセルで、1/2 の孤立点が増える。坂は画面でのまくらぎの間隔が 4px にならないため。ゲームでは見本の坂を等倍で見て、崩れは無かった（1/2 は撮っていない）
- スラブの直線では、締結装置がスラブの継ぎ目（タイルの辺から 2.5）の上にも来る。継ぎ目は動かしていない。等倍の画面では目立たなかった

## 決めたこと

- 線路の模様の間隔は、1/2 の画面（2×2 の平均）の格子と干渉しないようにそろえる。直線の画面で 4px おき（タイル 1 辺に 16 個）にし、タイルの辺の上に置く。斜め・坂は変えない（2026-11-21、ユーザーの決定。上の値）

- 道路・路面軌道（#89 の範囲外。道路は物差しの外）
