## 手本

`docs/reference/refs-index.md` のスラブ軌道の手本のうち、`../refs/sis/track/Shinkansen_Track/track/t2-slab/` の地上の single と、`../refs/iss/release/pak128/way/rail/standard_slab_g_single.png` の直線のセルを 7 倍で見た。

- どちらも、スラブの中（継ぎ目・突起・締結装置・汚れ）をほとんど描かない。スラブは「明るい帯 + 手前の縁の影」で読ませ、レールの 2 本の線が一番目立つ
- SIS はレールを赤茶の 1 本の線で描く。iss はレールを明るい頭と暗い赤の側面の 2 色で描く
- SIS の地上のスラブ軌道（`SIS_ST_TGsl_E01-999S`）のくどさ（下の物差し。way の画素には両側の壁と床も入る）: 細かさ 0.0240・孤立点 8.89。在来線で合わせた物差しでは「物足りない」の側に出る

## 分かったこと

- 明るい地（スラブ・雪）の上の 1px の線は、画面の 2:1 の斜めで点線になり、孤立点を増やす。明るい頭の帯（温暖）も、雪の上の細くしたレール（雪）も同じ。雪の孤立点が上がったのは、汚れた雪の縞が消えて、レールの点線が周りから浮いたため（見た目は在来線の雪と同じく、無地の雪にレールの線だけ）
- スラブ軌道の手本（SIS・iss）は、スラブの中をほとんど描かない。今の物差しでは SIS は「物足りない」に出るが、スラブ軌道として不自然には見えない。スラブ軌道の物差しは無い（在来線の温暖の絵で合わせたもの）
- 締結装置は、色を暗くしても明るくしても、誇張するとレールの脇の模様になり、まくらぎの代わりの拍子にはならなかった

## ラウンドの版の作り

- `round_rail_slab.py` の `apply` は、`R.TRACK_PROFILES` のうちシートの名前が `ami_rail_slab` で始まる描き分けの `replace`・`parts`・`skin`・`snow_skin` を写して替える（`sheetlib` のモジュールの値は書き換えない）。道床の幅は、`sheetlib` の `slab_bed_shape` と同じ形を半幅だけ替えて作り直した（`_bed_shape`）。分岐のすき間埋め（`bed_fills`）の上面の半幅も合わせた
- 本番に入れるときは、`sheetlib.slab_parts` の `SLAB_BED_U`・`SLAB_BED_TOP_U` と道床の色を直すか、`slab_bed_shape` に半幅の引数を足す。レールは `render.py` の `TRACK_SETTINGS` の `RAIL_SLAB` に、在来線の `railL`・`railR` の差し替えを渡す
