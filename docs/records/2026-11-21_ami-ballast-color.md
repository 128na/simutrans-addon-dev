# 作業ログ: AMI の在来線の砕石の色を変え、弾性まくらぎ直結軌道と見分けやすくする（#70）

（2026-11-21）

## 目的 / 発端

#62 で足した弾性まくらぎ直結軌道（`ami_rail_concrete`）は、道床の形を在来線（`ami_rail_ballast`）と同じにしたので、見分けは道床の色と肌だけになった。ユーザーは見た目を確かめ、在来線の側の色味を変えると決めた（#70 の本文）。色は精細化（#56）のラウンド 5 で決めた値（`BALLAST_DARK = 0.82`、色合いなし）を変える。

## 分かったこと（事実）

- 道床に足せない色: 赤み（`slope_measure.py` がこのアドオンのレールを「赤 − 青」の大きい箱で探す）に加えて、緑み（同じ道具が「緑が赤・青より強い」画素を地面とみなし、道床の縁をそこで止める）。変えられる向きは、暗さと青み。
- 試し方: 在来線の通常の版のシートだけを、砕石の 2 色だけ替えて描いた（試しの入口は `work/trial/` に置き、`render.py` の `_BALLAST_SKIN` の砕石の材質を差し替えた。今の値で描くと、シートは元と同じになった）。案ごとに pak を作り、見本（`sample_parallel.sh`、`BASE_PORT=47210`）の区画を撮った。

  | 案 | 変え方 | 砕石の 2 色（lo〜hi、RGB） |
  |---|---|---|
  | v0（変える前） | `BALLAST_DARK` 0.82 | (0.148, 0.141, 0.126)〜(0.541, 0.515, 0.481) |
  | v1 | 0.62 | (0.112, 0.107, 0.095)〜(0.409, 0.389, 0.363) |
  | v2 | 0.82・色合いの倍率 (0.90, 0.97, 1.10) | (0.133, 0.137, 0.139)〜(0.487, 0.500, 0.529) |
  | v3 | 0.66・色合いの倍率 (0.88, 0.97, 1.14) | (0.105, 0.110, 0.116)〜(0.383, 0.402, 0.441) |

- くどさ（`calib_capture.sh`・`busy_measure.py`、`flat_512.sve`、等倍、温暖、線を除く。ポート 47200〜47203）: v0 0.0720・21.51、v1 0.0720・23.21、v2 0.0720・21.88、v3 0.0718・22.82。どれも物差し（`way-addon.md` の 11 章）の「許容」。v0 は #62 の記録の値と同じ。
- 見た目: v1 は直結軌道と明るさで、v2 は色合いで離れる。v3 は両方で離れ、直結軌道（明るい中立の灰）との差がいちばん大きかった。汚れの帯（さび・油）は、青みの道床の上でも目立ち過ぎなかった（区画 `B` の 4 倍の切り抜き）。
- 継ぎ目と坂（`seam_slope_check.sh`、v0 は 47201、v3 は 47200）: 継ぎ目は v0 と同じ（東西・南北・坂 OK、斜めは前からの継ぎ目の草 1px で NG）。坂の合否も同じ（急坂 1 合格・3 不合格、1 段の坂 2・2）。寄りは、坂 36 だけ +1.71 → +1.35px と小さくなり、ほかは ±0.02px 以内。青みでレールの見つけ方は変わらなかった。
- 雪: 在来線と直結軌道は、雪の皮（`_BALLAST_SNOW_SKIN`）と道床の形が共通で、シートの雪の行が画素まで同じ（`sheet_diff.py`。違うのは夏の行だけ）。砕石の色では雪の見分けは付かない。
- 上の 2 点（v3 の推し、雪で見分けられないこと）を進捗管理経由でユーザーに上げた（issue #70 のコメント）。答え（2026-11-21）: 色は v3。雪は見分けなくてよい（#56 で決めた積もったばかりの雪のまま）。issue の「できたと言う条件」1 の「降雪」は、見分けの条件から外す。
- 本番に入れた後: 在来線の 11 シート（通常・基盤 4 版・高架 4 版・橋・トンネル）だけが変わり、輪郭（透過の範囲）の差は全シートで 0、色が変わったのは夏の行だけ。通常の版のシートは試しの v3 と同じファイル。直結軌道・スラブを描き直しても差は出なかった。
- ゲームの画面（`sample_parallel.sh`、区画 `AFC`・`B`・`DE`・`B_B`・`VS_B`・`BT_B1`・`BT_T2`）: 降雪側は変える前と画素まで同じ（ツールバーと状態行を除いて比べた）。温暖側は区画ごとに 2418〜25962 画素の色が変わった。
- 前に撮った直結軌道の見本（#62 の作業中の `work/sample_conc/`）は、道床の縁を在来線と同じ所で止める前のもので、縁が今より広く明るく写っていた。比べる画像は、今の pak で撮り直した。

## 推測・未確認事項

- ゲームでの見た目（色合いの好み・見分けやすさ）は、ユーザーが PR の画像とゲームで確かめる。
- くどさは温暖の地面の通常の版だけで測った（物差しの確かめた範囲と同じ）。基盤・高架の版では測っていない。

## 結果どうしたか

- `addons/ami/blender/render.py` の `BALLAST_DARK` を 0.82 → 0.66 にし、色合いの倍率 `BALLAST_TINT = (0.88, 0.97, 1.14)` を足した（汚れの帯の色は変えない。変えると直結軌道の絵も変わる）。在来線の 11 シートを描き直した。
- 確認画像は `addons/ami/docs/ballast_color_<気候>_<区画>.png`（左から在来線の変える前・変えた後・弾性まくらぎ直結軌道・高速線（スラブ）。下は黄色の枠の中の 4 倍）。
- `addons/ami/README.md` の在来線の道床の色と、直結軌道の雪の項に書き足した。
