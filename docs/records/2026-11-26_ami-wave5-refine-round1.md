# 作業ログ: 第 5 弾の物の精細化のラウンド 1〜3（色の舗装の走行跡・転車台のまわりと床、#331）

（2026-11-26）

## 目的 / 発端

#331。第 5 弾の物（#313 の路面の色・黄色の中央線・交差点の中心の印、#314 の転車台・遷車台）を、汚しと精細化のラウンドで磨き、
既存のアドオン（AMI の第 1〜4 弾と、手本の iss）と並べてなじむかを確かめる。進め方はスキル `way-refine-rounds`。

土台は今の本番（`render.py` の `MARKING_COLOR_ARGS`、`sheetlib` の `turntable.py`）。新しい系統 `wave5`（`addons/ami/blender/round_wave5.py`）を作り、
本番の値を書き換えずに、材質の差し替え（skin）と部品の足し・寸法の差し替えだけで試した。ラウンド 0（何も変えない `0null`）は、
今の `src/` とアイコン・カーソルのセルを除いて画素で同じだった。

なじみを見るため、見本に iss の同じ物を並べる区画を足した（色の舗装は `color_marking_sample.nut` の `PI`、転車台は `turntable_sample.nut` の `TI`。
iss の pak は `../refs/iss/release/pak128/iss_util_road_misc.pak`・`iss_util_rail_misc.pak` を `EXTRA_PAKS` で足す）。

## 分かったこと（事実）

### 意味の木

色の舗装（赤・青・緑）・赤の縞・黄線・中心の印:

| 部品 | 画面での大きさ | 前の絵 |

| 色の帯（中央線の両側に 1 本ずつ） | 幅 1.57 ≈ 11px | 一色のまだら（Scale 60）。下の一般道路の走行跡・油の帯を覆い、新品のように均一 |

### 葉ごとの試し（ゲームの画面。前と同じ位置・等倍で並べて見た。拡大は 2〜3 倍で確かめただけで、判断は等倍）

| 鍵 | 中身 | 判断 |
|---|---|---|
| 1wp | 帯の上に走行跡（`WEAR_LAYERS` の 2 段目の位置）を通し、帯の色を走行跡の灰色へ 0.5 寄せた粗いまだら | 等倍で、帯の中の明るい 2 本の筋として見える。**採る** |
| 1wp2 | 1 段目の広い幅で 0.35 寄せる | 帯全体が灰色にくすみ、色が弱まる。採らない |
| 1lift | 色の舗装の色を 1.6 倍（赤の縞も同じ赤なので明るくなる） | 等倍ではっきり明るくなり、iss と並べても沈まない。**採る**（値の変更。判断できない点に書く） |
| 1ap | まわりのコンクリートを線路の基盤と同じ肌（段 2）、壁に床際の汚れ | 拡大でだけ見える。等倍で見分けられない。採らない |
| 1fl | ピットの床を砂利と泥のまだら（±25%、粒約 1px）と大きなしみ（25%） | 等倍で見える。採る（ラウンド 3 で直した） |
| 1cp | 縁の黄色の帯を 0.36 に誇張 | 等倍で縁が見える（iss の縁の太い橙に近づく）。**採る** |
| 1pt | 桁・台車の塗装の汚れのまだら | 桁はまくらぎに隠れ、等倍で見えない。採らない |
| 2ring | まわりを、ピットの縁から 0.9 の輪にし、角は地面 | 浮いた四角が消える。輪が明るく、草の中で縁が目立つ |
| 2ringd | 2ring に、色を 0.50 に下げて段 2 の肌 | 線路の行き止まりの灰色となじむ。**採る** |
| 2win | 運転室の 4 面に窓の暗い帯（高さ 0.25） | 等倍で暗い 2px の帯として見える。**採る** |
| 3fl2 | 1fl から大きなしみを外す | ラウンド 2 の遷車台の長いピットで、しみがタイルごとに同じ形で並んで見えた（2026-11-15 の補修跡と同じ）。しみを外すと並びが消え、床の暗さと粒は残る。**採る** |

### ラウンドの版

- ラウンド 1: 1wp・1lift・1fl・1cp（`ROUND_SETTINGS["1"]`）
- ラウンド 2: 1 に 2ringd・2win（`"2"`）
- ラウンド 3: 2 の床を 3fl2 に（`"3"`）。pak は `addons/ami/rounds/ami_wave5_round3.pak`

### 評価（前と比べて。ラウンド 3）

| 観点 | 判定 | 理由 |
|---|---|---|
| ① 欠陥 | 同じ | `check.sh` が通る。輪の外の角は地面で、線路の行き止まりとの間に隙間は出ない（輪の外の半径 5.5 がタイルの辺の中ほど 5 を越える）。遷車台の床はタイルの辺でつながる（`tiled_concrete_material`） |
| ② 写実 | 良くなった | 色の帯の走行跡、ピットの床の砂利、窓が加わった。縁の帯が見える |
| ③ くどさ | わずかに増 | 足したのは帯の 2 本の筋・床の細かい粒・窓の帯。`busy_measure.py` は流していない（物差しは在来線の温暖の絵で合わせたもので、路面表示・転車台の物差しが無い） |
| ④ そろい | 良くなった | まわりの輪の肌は線路の基盤・壁と同じ段 2。転車台と遷車台の縁・床・窓は同じ作り。色の舗装の走行跡は下の道路の走行跡と同じ位置を通る |

### 本番に入れたもの

- `tools/blender/sheetlib/marking.py`: `marking_sheet` に `wear`（走行跡の材質）、`_Plan.wear`、`_color_bands` の `wear`、`MARKING_COLOR_WEAR`。`wear` を渡さなければ前と同じ絵（ほかの路面表示 17 枚は描き直して前と画素で同じ）
- `addons/ami/blender/render.py`: `MARKING_COLOR_LIFT`（1.6）・`MARKING_COLOR_FADE`（0.5）・`_marking_faded`、`TURNTABLE_SKIN`
- `tools/blender/sheetlib/turntable.py`: `COPING_W` 0.18 → 0.36、`TT_APRON_W`（輪）、`HUT_WINDOW`（窓）、`turntable_sheet` の `skin`。AMI だけが使うモジュールなので、形は既定の値を変えた
- 本番で描いたシートは、ラウンド 3 のシートと（アイコン・カーソルのセルを除いて）画素で同じ

## 推測・未確認事項

- 1lift は #313 でユーザーが見た色の値を変える。値の判断はユーザーに残す（戻すなら `MARKING_COLOR_LIFT = 1.0`）
- 色の舗装の色み: 1lift の後も、AMI の赤は茶に寄り、iss の赤（深紅）と色みが違う。日本のバスレーンの赤は茶に近いと見て変えていない（未確認）
- 降雪: 色の舗装は夏と同じセル（雪の絵を持たない）。転車台の雪の絵は、床とまわりが雪の材質のままなので、輪の形と縁・窓だけが変わる
- 交差点の中心の印・黄線は試していない（1px の線で、前例から見分けられないと見た）。印の位置・形は #313 で決めたとおり
- くどさの値は測っていない

## 結果どうしたか

ラウンド 3 を本番に入れ、色の舗装 4 枚と転車台のシートを描き直した（PR は #331 の PR）。前後の画像は `addons/ami/docs/331_refine/`。
