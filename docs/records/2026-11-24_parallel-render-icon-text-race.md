# 調査/作業ログ: 全対象の並列描画だけシートが違う原因（#244）

## 目的 / 発端

#229（記録 `2026-11-24_ami-sheet-drift-audit.md`）で、AMI の全対象を 1 回で並列に描いた回だけ、`ami_rail_concrete_elev_single`・`ami_rail_concrete_old_elev_front`・`ami_rail_ladder_elev_back` がコミット済みの絵と違い、単独で描くと一致した。原因を絞る。

## 分かったこと（事実）

- 原因は `blender/icons.py` の文字の一時ファイル `work/_icon_text.png`（文字を描いた絵の書き出し先）が、全プロセスで同じ名前だったこと。`render.py` は対象ごとに、描いた後で別の Blender で `icons.py --own` を動かす。`render_parallel.py` で並べて描くと、この後処理が何本も同時に動き、同じファイルへ書いて読み合う。読んだ文字の絵が別のプロセスのものになり、アイコン・カーソルの札の字が欠けたり、別の対象の字が混ざったりする。
- 再現（2026-11-24、Blender 4.5.16）:
  - 全 210 対象を `render_parallel.py` で 1 回描く（13 分）: 描いた直後のシートがコミット済みと違った物が複数あり（`ami_rail_slab_old_elev_single` など）、その回の違いは毎回別の対象になる。`icons.py`（全部）を流すと、全 PNG がバイト単位で一致した。
  - 高架の線路 36 対象だけを並列に描く: `ami_rail_concrete_old_elev_back`・`ami_rail_ladder_old_elev_center`・`ami_rail_ladder_old_elev_single` など 1〜2 枚が違った。違いはアイコン（0.0）とカーソル（0.1）のセルだけで、カーソルの札（「240後」「360速」）が欠けるか色がずれていた。タイルのセルは同じ。`icons.py` をその対象だけ単独で流すと一致した。
  - 最小の再現: 高架の線路 20 対象の `icons.py --own` を同時に流すと（約 8 秒）、14 枚がコミット済みと違った。1 本ずつ順に流すと 20 枚とも一致した。
- 直し: 一時ファイルの名前を `_icon_text_<PID>.png` にし、読んだ後に消す。高架の線路 36 対象の並列描画を直して 1 回描き直すと、後処理を流す前から違いが 0 枚だった。直した後は、同じ 20 対象の同時実行を 3 回繰り返して違いが 0 枚。210 対象を 24 本ずつ同時に流しても、PNG は 0 枚が違った。
- #229 の高架 3 枚が、後処理（`icons.py` 全部）の後も違ったように見えた理由は、確かめていない。今回の再現では後処理を全部流すと必ず一致した。#229 の時点の比べ方（途中の状態を比べた、別の回のシートと混ざったなど）の可能性がある。
- 付随して、`work/_icon_text.png` の取り合いは、並列描画した全部のシートのアイコン・カーソルに起きうる（高架の 3 枚に限らない）。#229 で見つけた「札が違う 5 枚」（コミット済みの札の字が違った）の一部も、同じ原因の可能性がある（未確認）。

## 推測・未確認事項

- 上の「札が違う 5 枚」と本件の関係。5 枚は今は直してあり、再発するかは今後の並列描画で見る。
- 並列の描画本体（Blender の描画）には、シートの内容を変える取り合いは見つからなかった。`check_tile_flat`・`check_tile_up12` は全対象で共通の名前だが、シートには入れない確認用。

## 結果どうしたか

- `addons/ami/blender/icons.py` の一時ファイル名を直した。リファレンス `docs/reference/way-addon.md` の 8.2 に道具の癖として書いた。
- 比べるときの決まり（描いた後に `icons.py`（全部）を流してから比べる）は変わらない。
