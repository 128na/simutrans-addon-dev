# 作業ログ: AMI の路面軌道（#23）

（2026-11-20）

## 目的 / 発端

手順の一覧（#27）の 11 番目。AMI に路面軌道（`ami_tram`、waytype `tram_track`）を足す。値は README の表（60 km/h・10000・200・1900）。ADR 0002 のとおり、路面軌道は道路に重ねて敷く想定で作る。

## 分かったこと（事実）

- 本体は `tram_track` を track の `system_type=7` として読む。スクリプトでは `get_way(wt_rail)` で取れ、分岐の絵の固定は `"" + wt_rail + ",1/2"` で効く。分岐の絵（`nse1`〜`nsew2`）の自動選択は線路と同じ `select_switch_image` を通る（ゲームで区画 H の 8 通りがどれも通常の T字と違う絵になった）
- AMI の橋脚 `ami_pier_*` も `tram_track` なので、路面軌道が橋脚の列を横切ると、そのタイルは路面軌道に置き換わり、隣の橋脚とつながる（区画 P の `[check]` が `cross=ami_tram west=ami_pier_rail north=ami_tram`）
- 道路の上に敷いたタイルは道路と路面軌道の 2 本の way になり、`has_two_ways()` は真になる。土の上の近い斜めでは偽（近い斜めの絵）
- 位置の手本: pak128 の `Tram_Track_050_A` はレールの中心を道路の中心線に重ねている。AMI のシートの線路の基準（`128+BALLAST_DY`）では道路の中心から 2px ずれるので、路面軌道は道路と同じ基準（`ROAD_CY`）で描いた。ずれは 0.5px 以内（`ref_measure.py` で測った）

## 直したこと

- `tools/blender/sheetlib/tram_parts.py` を足した。床（コンクリートのまだら）・縁の明るい帯・溝・目地・レールの頭と、線路の汚れ（さび・油）を床の上の帯に差し替える `TRAM_WEAR_REPLACE`、雪の絵で夏と同じ材質に戻す `TRAM_SNOW_SKIN`
- `track_sheet` の断面の基準を、TRACK_PROFILES の `anchor`・`cy` で変えられるようにした（無ければ今までどおり）。既存のシート（`ami_rail_ballast`・`ami_road_general`・`ami_pier_road`）は描き直してバイト単位で同じだった
- `core.FLAT` に `tram_bed` を足した（アイコンの組み立てで要る）
- `addons/ami/blender/` の catalog・render・ami_dat・addon_config に `ami_tram` を足した。`ami_dat.py` の `TRAM_SWITCH_IMAGES`（既定は真）で分岐の絵を書くか切り替える
- 見本 `ingame/tram_sample.nut` と撮る場所 `sample_spots.sh` の `TRAM_SPOTS`（47 か所）
