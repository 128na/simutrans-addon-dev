# 作業ログ: 道路一式の精細化のラウンド 1（路面、#56）

（2026-11-20）

## 目的 / 発端

在来線のラウンド 1〜8（`2026-11-20_ami-refine-round1.md`〜`round8.md`）の流れ（スキル `way-refine-rounds`）を、AMI の道路一式（`AMI_FAMILY=road`。道路 3 種と基盤・高架・橋・トンネル、道路の壁、道路用の橋脚、歩道）で回す。ラウンド 1 は路面（アスファルトと走行跡）。土台は今の `render.py`（ラウンド 0 = `rounds/ami_road_round0.pak`）。

## 準備

- 見本の nut（`road_sample.nut`・`road_struct_sample.nut`・`road_junction_sample.nut`・`sidewalk_sample.nut`）に、`sample.nut` と同じ `SUFFIX` を足した（`ami_` で始まる名前にだけ付ける。`road_struct_sample.nut` の線路 `RAIL` は道路のラウンドの pak に無いので今の名前のまま）。ラウンド 0 の見本で、`[check]` の名前が全部 `_round0` になることを確かめた（橋・トンネルの上の way も `_round0`）
- くどさを測る道路の見本 `ingame/calib_road.nut` を作った（`calib.nut` と同じ並び。敷けた way の名前の確かめは way の種類に合わせる）
- 空のラウンド（`ROUND_SETTINGS["0null"]`）で道路 3 種・歩道・壁・橋脚・橋・トンネル・高架を描き、今の `src/` とバイト単位で同じことを確かめた
  - 最初は歩道だけ違った。`sheetlib/sidewalk.py` が一時フォルダ `WORK` を名前で取り込んでいて、`round.py` の `_run` の切り替え（core・cells・sheetlib の `WORK`）に付いていかない。持ち分の画像（`_own.png`）を `work/` に書き、cells はラウンドの一時フォルダから読むので、歩道の絵がずれた。`round_road.py` の `apply` で `sidewalk.WORK` もそろえた（`round.py` を直すまでの間。本番に入れるときに `round.py` の `_run` で直す）
- 道路の描き分け（`road_sheet`）は、プロファイルから材質（`skin`）しか差し替えられない。走行跡の形を変える試しは、このプロセスの中だけで `sheetlib.sheetlib.ROAD_PARTS` を差し替えた（`round_road.py` の冒頭に書いた）

1binw を一式にしたもの（`1a`）をゲームで撮ると、路面が暗くなった（一般道路 52 → 43、高速道路 29 → 24）。照り返しと明るい走行跡が減った分で、手本（iss 74・35、pak128 104）から離れる向きなので、路面の色を明るくして戻した（`1b` で直線のセルの明るさを合わせ、高速道路は十字の走行跡が減って暗いので少し足した）。

## 本番に入れるときに直す所

- `road_parts.py` の `_M_ROAD_ASPHALT` に照り返しの指定（`spec=0.0`）と色を足す。走行跡の材質（`_wear_material`）と、まだらの雪も同じ色から作る（`asphalt_skin` に細かさ・色の段の口を足す）
- まだらの色の段（`noisy_material` の 0.35・0.65）を渡せる口を足す（既定は変えない。在来線・blender-poc の絵が変わる）
- `road_sheet` に部品の差し替えの口（`replace`）を足し、走行跡の寄せ具合を種類ごとに渡せるようにする
- `round.py` の `_run` で `sidewalk.WORK` も切り替える
