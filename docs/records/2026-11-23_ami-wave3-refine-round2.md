（2026-11-23）

## 目的 / 発端

ラウンド 1（`2026-11-23_ami-wave3-refine-round1.md`）の続き。止める合図（くどさで「悪くなった」）が出るまで回す。土台はラウンド 1（1wl2 + 1chip2。運河の水面の葉は外してある）。

## 準備

- 路面表示の見本の nut（`marking_sample.nut`・`marking6_sample.nut`・`expwy_marking_sample.nut`）に、`sample.nut` と同じ作りの `SUFFIX`（`ami_mark_` で始まる名前の末尾に付ける）を足した。ラウンドの版を、ゲームで隣の道路と並べて撮れる（`sample_parallel.sh` の `SUFFIX`・`EXTRA_PAKS`）。ゲームで並べる撮影は、このラウンドでは流していない

## 葉ごとの試し（セル。画像 `addons/ami/docs/197_rounds/r2_cells.png`、4 倍。上から lane6_m の雪、junction6_m の三角、景観の運河）

| 鍵 | 中身 | 判断 |
|---|---|---|
| 2slush6 | 雪の縁のぼかしの段を 4 → 6（幅 0.8 のまま。`MARKING_SLUSH_T`） | 縁がなめらかになった。採る |
| 2wl3 | 景観の運河の水際の染みの高さを 1.2 → 1.8 | 壁の上まで灰緑に汚れ、くどい。採らない |

`ROUND_SETTINGS["2"]` = ラウンド 1 + 2slush6（pak は作っていない。作るときは、描いてから `AMI_FAMILY=wave3 python -X utf8 blender/round.py 2`）。

## 評価（ラウンド 1 と比べて）

| 観点 | 判定 | 理由 |
|---|---|---|
| ① 欠陥 | 同じ | 輪郭の差は 0 画素（`sheet_diff.py` の alpha、3 シートとも）。`sheet_audit.py` は流していない |
| ② 写実 | 同じ〜少し良くなった | 雪の縁がなめらか。2wl3 は壁が汚れすぎた（採らない） |
| ③ くどさ | 2wl3 で悪くなった、2slush6 は同じ | `busy_measure.py` は流していない（ゲームの画面での測定が要る）。見た目で判定 |
| ④ そろい | 同じ | |

止める合図: 2wl3 で「くどさ」が悪くなり、ほかの葉もほとんど「同じ」。ラウンドを止める。

## 判断できない点

- `sheet_audit.py`・`busy_measure.py`（くどさ）を流していない。前者はアドオンの `src/` を対象にする作りで、ラウンドのシートだけを置く場所が要る。後者は、ゲームで前後を並べて撮る必要がある
- 本番に入れるかは、ユーザーの判断だった（下の「本番に入れた結果」）

## 本番に入れた結果（PR #218、2026-11-24）

ユーザーの決定（「それぞれおすすめでOK」）で、1wl2（景観の運河の壁の水際の染み）と 2slush6（路面表示の雪の縁 6 段）を本番に入れた。1chip2（白線の塗料の欠け）は入れていない。変わった本番のシートは `ami_canal_scenic`・`ami_mark_lane6_m`・`ami_mark_junction4_in・out`・`ami_mark_junction6_in・m` の 7 枚だけ。前後の画像は `addons/ami/docs/197_final/`。入れ済みの葉を `round_wave3.py` の設定に重ねると二重にかかる。
