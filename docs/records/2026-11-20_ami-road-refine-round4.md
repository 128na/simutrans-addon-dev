# 作業ログ: 道路一式の精細化のラウンド 4（生活道路・一般道路の路面の明るさ、#56）

（2026-11-20）

## 目的 / 発端

道路一式の精細化（`2026-11-20_ami-road-refine-round3.md` の続き）のラウンド 4。これで 4 ラウンド目なので、このラウンドで止める。土台はラウンド 3（`ROUND_SETTINGS["3"]`）。

ラウンド 1 から残っていた点を扱った。ゲームの画面で、生活道路・一般道路の路面の明るさ（way の画素のうち明るさ 150 未満の平均）を一般の道路の手本と比べると、次のとおり。

| | 明るさ |
|---|---|
| AMI 一般道路（ラウンド 3） | 51 |
| SIS 一般道 | 67 |
| iss `iss_wrg_0050` | 74 |
| pak128 `Road_050` | 104 |

AMI の一般道路はどの手本よりも暗い。README には「pak128 標準の道路（灰色）とつなぐことが多いので街路の灰色」とあり、この決まりからも離れている。高速道路（29）は手本（SIS 高速道路 30・iss 35）と同じくらいなので変えない。

## 葉ごとの試し（一般道路の直線のセル 0.1、白線を含む明るさ）

| 鍵 | 中身 | セルの明るさ | 判断 |
|---|---|---|---|
| ラウンド 3 | 路面の 2 色を 2.4 倍 | 69 | — |
| 4lift | 3.2 倍 | 76 | 弱い |
| 4lift2 | 4.0 倍 | 81 | 弱い |
| 4lift3 | 5.5 倍 | 90 | 明るさは目安（ゲームではセルより約 18 暗く出るので、セルで 85〜92）に入る。ただし油の帯が黒い筋として浮く |
| 4lift4 | 7.0 倍 | 97 | 明るすぎる。油の帯が浮く |
| 4oil | 4lift3 + 油の帯も同じ倍率 | 90 | 黒い筋が消え、灰色の路面になる。採る |

- 油の帯（`road_parts` の `_M_OIL`）は色が固定で、ラウンド 1 で路面だけ 2.4 倍にしたときから、路面に対して暗く寄っていた。路面をさらに明るくすると差が開く
- 4oil では油の帯の 2 色に、路面と同じ倍率をかけた（生活道路・一般道路は `street_lift`、高速道路は `expwy_lift`）。道路の描き分けの skin の `"oil"` に入れたので、3 種で同じ作りのまま
- 画像: `addons/ami/docs/road_round4_leaves.png`（上: 一般道路の直線のセル 0.1、下: 直線のセル 1.0。左から ラウンド 3・4lift2・4lift3・4oil。3 倍）

## 止めた理由

4 ラウンド回したので止める（仕事の決まり）。見て残っている候補は次のとおり。

- 路肩・壁の継ぎ目・遮音板: どれも形を差し替える口が無く、材質だけの葉では扱えない
- 白線: ラウンド 3 で手本と同じ明るさと分かった

## 判断できない点

- 道路のくどさの物差しが無い（ラウンド 1〜3 と同じ）
- 明るい路面では、走行跡の帯（路面より明るい、粒のある帯）がラウンド 3 より見える。生活道路の高架の画面で目に付く。数字（孤立点）は減ったが、見た目の好みが分かれうる
- pak128 `Road_050`（104）よりはまだ暗い。手本の iss・SIS に合わせた

## 本番に入れるときに直す所

- `road_parts.py` の `_M_ROAD_ASPHALT` の色を明るくする（`STREET` の 5.5 倍）。油の帯（`_M_OIL`）・走行跡・まだらの雪も、同じ倍率の色から作る（`asphalt_skin` に油の帯を入れる）
