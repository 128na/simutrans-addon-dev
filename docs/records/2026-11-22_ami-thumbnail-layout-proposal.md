# 作業ログ: 第 2 弾のベータ版のサムネイルの撮影用レイアウトの提案（#103）

（2026-11-22）

## 目的 / 発端

[#103](https://github.com/128na/simutrans-addon-dev/issues/103) は、サムネイルの構図をスクリプトで作る仕組みを求めていた。ユーザーの判断（2026-11-22）で、仕組みは作らない（更新はパーツが増えたときや、目立つ物が足されたときだけにとどめ、全自動は工数が割に合わない）。代わりに、今のラインアップから撮影用のレイアウトを提案する。ゲームで敷くのは、ユーザーが求めたときだけ。

材料は、#103 のコメントのユーザーの言葉（コンセプトと、含めること）、#96 の手動の構図（`ingame/thumbnail.nut` の頭のコメント）、[ADR 0008](../adr/0008-ami-scope-second-phase.md) の第 2 弾の範囲、`addons/ami/README.md`。

## 画面の前提

- 撮るのは等倍（`gui.set_zoom(3)`）、2560×1340（OGP の 1.91:1）。タイルの中心は x = 1280 + 64·(dx−dy)、y = 670 + 32·(dx+dy−2)。画面に入るのは、おおよそ (dx−dy) が ±20、(dx+dy) が ±21。
- 東西の線（dx が増える向き）は画面の左上から右下へ、南北の線（dy が増える向き）は右上から左下へ走る。
- 題名は左上（上の帯）、内容の文字は左下。左上と左下は、見せたい物を置かず、道路の碁盤か空き地にする。
- 検証の保存データ `flat_512.sve` は、x=256 が気候の境目（x<256 が温暖、x≥256 が降雪）。画面では、x=256 の線が右上から左下へ斜めに走り、**右下が降雪、左上が温暖**になる。題名・文字の側（左）が温暖で、見せ場が降雪にかかる。

## 配置の見取り図（案）

原点 C = 大通りと在来線のクロス（x=256 の東 6 タイル）。図は画面の向きではなく**タイルの向き**で描く（上が dy の小さい側、右が dx の大きい側。画面では、この図を時計回りに 45° 回した向きになる）。区画の大きさはおおよその目安。

dy
-16   [題名の空き:生活道路の碁盤] [高速道路 高架+分離帯 ======IC=====]  ← 高速道路
-12   [        空き        ] [モノレール 跨座式 ＝＝ 懸垂式 ＝＝＝]    ← 降雪側
 -8   [路地:歩道・電柱     ] [  運河 ～～ 水路の踏切 ～～     ]
 -4   [ 丘+トンネル坑口 → ][ 在来線+直結軌道(複線) ]  ┐  高速線の高架
  0   [  ═════ 大通り(4 車線、路面表示) ═════      ] ├─ ×クロス

置く物の一覧（名前は README のラインナップによる）:

1. **高速道路〜IC〜幹線〜路地裏**（画面の上から下へ）
   - `ami_road_expressway_elev_*` に中央分離帯つきの壁（`ami_wall_road_*_divider`）、真下に `ami_pier_road`。路面表示の版（`ami_road_expressway_lane<n>`）で車線を見せる。
   - IC は、高速道路から下りて大通り（`ami_road_general_lane4` 前後）へ曲がる 1 本。
   - 大通りから生活道路（`ami_road_local`）へ入り、歩道（`ami_sidewalk_*` の舗装の種類を街区ごとに替える）と電柱・標識（`ami_sidewalk_pole_*`・`ami_sign_*` から 1〜2 種）。
2. **複線の鉄道**
   - 地上: 在来線（`ami_rail_ballast_base_*`、架線つきの壁）と直結軌道（`ami_rail_concrete_base_*`）の組。
   - 高架: 高速線（`ami_rail_slab_elev_*`）とラダー軌道（`ami_rail_ladder_*`）の組。地上の複線の上を斜めに越える。橋脚（`ami_pier_rail`、大通りの上だけ門型）は、下の構造物と重ならない所に立てる。
   - トンネルは在来線の丘の坑口 1 つ（線が来る側に口が開く）。橋はラダー軌道が大通りを越える 1 か所。
3. **車両基地**（温暖側、画面の下の中ほど）: 車庫（`ami_rail_depot`）、操車場（`ami_rail_yard`）、在来線から分かれる Y 字・三方分岐。壁の無い版で敷く（壁つきの線の間の渡り線は崩れる。#101）。
4. **モノレール 2 種**（降雪側、画面の右上）: 跨座式（`ami_monorail_straddle_elev_*`、電化は `ami_monorail_power`）と懸垂式（`ami_monorail_suspended_elev_*`、電化は `ami_monorail_suspended_power`）を、電化つきで平行に。降雪の絵で見せる。
5. **運河と水路の踏切**（降雪側、右）: 運河（`ami_canal`）を横切る道路に、跳ね橋の踏切（水路の踏切）（`ami_crossing_road_general_canal`）。
6. **路面軌道**: 大通りから生活道路の街区を回る 1 周（`ami_tram`）。道路と同じタイルに橋脚は置かない。

## 気候の境目の使い方

- 東西の線（高速道路の高架、高速線の高架、運河側の道路）を、x=256 をまたいで通す。同じ物が温暖と降雪で並ぶので、雪の絵（雪の道床・雪の壁）が出来ていることが 1 画面で伝わる。
- 題名・文字の側（左）は温暖、見せ場（モノレール・運河・高速線の高架）は降雪にかかるので、題名と見せ場が重ならず、色が左右で変わって単調さも崩れる。
- 土地を上げたタイルは雪でなくなる（[way-addon.md](../reference/way-addon.md) の 8.2）。丘（トンネル）は温暖側に置く。降雪側は平らのまま。
- 気候は `tool_set_climate`（範囲指定）でも変えられるので、境目を動かしたいときは使える。

## 避けること（#96 で分かったこと）

- 高架の床は、その北のタイルを隠す。高架のすぐ北（dy の小さい側）に見せたい物を置かず、1 タイル空ける。
- 歩道（`water`）が道路を横切ると踏切が立つ。南北の道路の所で歩道を切る。
- 橋脚（`tram_track`）は路面軌道と同じタイルに置けない。
- 木は植えられない（Trees disabled）。緑は街区の空き地で出す。
- 「直線が多く、灰色で味気ない」を避けるため、IC の曲がり・丘・運河・雪を、画面の対角に散らす。

## 確かめたゲームの癖（ゲームは `OTRPv64_3`、`flat_512.sve`、2026-11-22）

- 気候の境目は x=256 の縦線。`square_x(x, y).get_climate()` が x≤255 で 4（温暖）、x≥256 で 7（降雪）を返した（x=250〜262、y=100）。境目をまたぐ道路（`ami_road_general`、x=246〜266）を敷けた。
- 敷いた way は、起動したまま消せる。`command_x(tool_remove_way).work(pl, a, b, ""+wt_road)` が約 0.16 秒で返り、結果はすぐに反映される。
  - 範囲の**両端のタイルは残り**、間のタイルだけが消える（x=255〜257 で 256 だけ）。1 タイルだけ消すときは a と b に同じ座標を渡す（255,255 で 255 が消えた）。
  - 範囲の途中が途切れていると "Ways not connected" になる（258〜262 の間の 259 が無いとき）。部品ごとに、つながった範囲で消す。
  - 範囲の内側を消して `build_way` で敷き直すと、元に戻った。
- 起動したまま範囲を絞って敷き直せるが、#103 の仕組みは作らないので、使うのは見本を試すときだけ。
