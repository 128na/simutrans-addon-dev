# 作業ログ: 精細化のラウンド 5（道床の肩とのり面、砕石と床の明るさ、#56）

（2026-11-20）

## 目的 / 発端

ラウンド 4（`2026-11-20_ami-refine-round4.md`）で、まくらぎを明るい PC の色にした。
その結果、高架（区画 VS_B）では線路の帯（明るいまくらぎと砕石）が床のコンクリート（明るい灰色）と同じくらいの明るさになり、線路と床の境が弱くなった。
意味の木の次の枝（道床の形と、砕石・床の材料）を試した。

## 意味の木（道床と床の枝）

- 道床: 砕石を盛ったもの
  - 肩: まくらぎの端の外に、まくらぎの上面の高さで平らに広がる → 試した（shoulder）。今の形は、まくらぎの周りだけを上面まで埋め（ラウンド 2 の embed）、その外は低い台形（高さ 0.12）だった
  - のり面: 肩から床まで斜面 → 肩と一緒に試した。斜面の向きで明暗が付く
  - 砕石の色: 使い込んだ砕石は、新しいコンクリートより暗い灰色 → 試した（dark）
- 床（高架の床版・基盤の版の基盤）: コンクリート。雨だれでくすむ → 試した（deck）
- ケーブルトラフ・保守用通路: 道床の裾（±1.9）から壁の内側の面（約 ±2.04）まで約 0.14（約 1px）しかなく、置く場所が無い → 省く
- 壁の足元の汚れ（排水）: 壁は別の way（`ami_wall_rail_*`）で、床の絵の側からは壁のある辺だけに描き分けられない → このラウンドでは扱っていない

## 分かったこと

- 道床の肩とのり面は、高さが 0.18 しかないので、形を変えても画面では 1〜2px ののり面にしかならない。効くのは、砕石の色と組み合わせて縁に暗い帯を作るとき
- 線路と床の分かれ目は、床の側をくすませるより、砕石の側を暗くする方が、床が重くならずに分かれた（床は高架の広い面を占めるので、暗くすると全体が沈む）
