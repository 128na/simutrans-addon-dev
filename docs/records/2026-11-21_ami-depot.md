# 作業ログ: AMI の車庫（線路・路面軌道・道路）を作る（#112）

（2026-11-21）

## 目的 / 発端

[ADR 0008](../adr/0008-ami-scope-second-phase.md) の第 2 弾の物として、線路・路面軌道・道路の車庫（`ami_<種類>_depot`）を作る（#112）。値は AMI の README の「第 2 弾の物の値」（#110）で決めてあり、`cost`・`maintenance` を省かずに書く。手本は blender-poc の料金所（1 タイルの building に奥と手前の絵）。

## やったこと

- 描く共通部分 `tools/blender/sheetlib/depot.py` を足した（`building_sheet`・`depot_sheet`）。物を Z 軸まわりに 90 度ずつ回して 4 つの layout を描き、物ごとに奥・手前の層を選んで別々に描く（`visible_camera` を切り替え、影は残す）
- AMI 側: `blender/catalog.py` の `DEPOTS`、`blender/ami_dat.py` の `depot_dat_text`、`blender/render.py` の `SHEETS`、`blender/icons.py`（車庫のアイコン。札は「庫」、絵はタイル 1 枚を 1/4 にする）
- 最初は切妻の屋根の車庫を描いてローカルにコミットした（`32fb811`）。その後、ユーザーが「箱積み駅舎の箱のサイズを意識して落とし込みたい」とし、寸法は #140 で決まった（1 タイル × 高さ 2 段 = 32px。六角形 (64,32)(128,64)(128,96)(64,128)(0,96)(0,64) の中、128px のセルの座標）。屋根の棟が 32px を超えたので、平らな屋根の箱に描き直した（進捗管理から「平らな屋根で 32px ちょうどでよい」）
- 検査 `addons/ami/check_depot.py` を足し、`check.sh` から回すようにした。わざとオフセットを -100 にして、24 件の誤りが出ることを見た
- 見本 `addons/ami/ingame/depot.sh`・`depot.nut` を足し、`addon_check` の写し（`work/depot_game/47400/`）で温暖・降雪に敷いて撮った

## 分かったこと（事実）

- 道の出る向きと layout: 南 0・東 1・北 2・西 3（`simtool.cc` の `tool_depot_aux`）。ゲームで 4 つの向きを建てて、入口が道の側に向くことを見た
- 奥の絵と手前の絵の分け方: 南・東の壁（画面の手前）と屋根を手前の絵、北・西の壁を奥の絵にした。手前の壁の内側の面を奥の絵に描くと、車庫の床の way を隠したので、内側の面は北・西だけを描く（入口の脇の柱も入口の壁の側にした）
- 奥の絵の上端は、全部の layout・季節で y32、手前の絵は y36。48 枚すべてが六角形の中（`check_depot.py`）。本体の `get_drawn_height` で 2 段になる
- 高架: `ami_rail_ballast_elev_single` を AMI の車庫と pak128 の `TrainDepot` の上（z=2）に敷けた。このゲームの高架の高さは 2 段
- pak128 の車両の車体の高さ（南向きの絵で、画素の範囲の高さ − 幅/2。754 両）:

| 種類 | 両数 | 中央 | 上位 1 割 | 最大 |
|---|---|---|---|---|
| 線路 | 446 | 10.5px | 12.5px | 24px |
| 路面軌道 | 70 | 12.5px | 24px | 25px |
| 道路 | 238 | 9.5px | 17.5px | 24px |

  入口の高さを 26px にした（全部が入る）

- 道路の行き止まりの絵はタイル全体を塗り、地面より 1px 下に描かれる（cells の `ROAD_CY`）。車庫の手前の下の縁から道路の端が見えた。腰壁を地面より 0.13（約 1px）下へ延ばして減らした。0.26（約 2px）にすると六角形の外へ出たので戻した。1px の点線は残る
- 路面軌道: 1930 年の保存データでは電化の要らない路面軌道の車両が無く（`T-113` は電化が要る）、路面軌道の車庫から編成を出せなかった
- 道具の癖
  - `sheetlib` の `__init__` は、名前の頭が `_` 1 つの物も全部を外へ出す。`depot.py` の `_M_WALL` が壁の部品の同じ名前を上書きしたので、車庫の名前は `_M_DEPOT_*`・`_depot_*` にした
  - `depot.sh` の起動の出力を `tail` に渡すと、ゲームが出力を開いたままにするので終わらない。ファイルに出す
  - script に `world.set_pause` は無い（エラーの窓が出る）

## 修正の回数

- 箱の寸法: 切妻 → 平らな屋根の箱（1 回）
- 腰壁: 1px（入れた）→ 2px（六角形の外。戻した）（2 回）
- 奥・手前の分け方: 内側の面（1 回）

- 路面軌道の車庫から出る車両は見ていない。本家 125 での読み込みは見ていない
- 手元に Hako の pak が無く、箱積み駅舎と並べては見ていない
