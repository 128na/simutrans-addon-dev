# 作業ログ: 精細化のラウンド 4（まくらぎと道床の釣り合い、#56）

（2026-11-20）

## 目的 / 発端

ラウンド 3（`2026-11-20_ami-refine-round3.md`）のレールは、ユーザーの評が「シャープになった。いいね」だった。
レールが軽くなった分、まくらぎの間の暗い点が目立っていたので、意味の木の次の枝（まくらぎ・道床・汚れ）を試した。

## 暗い点の正体

直線のセルで、線路に沿う向き（画面で右へ 2・上へ 1）に明るさを並べた（`ami_rail_ballast` の 0 行 2 列、中心の列）。

- レールの間: まくらぎ約 160 と、まくらぎの間 50〜70 が交互に並ぶ。ほぼ黒の梯子
- レールの外: 130〜170 で穏やか（さびの帯）

レールの間の暗さは、油の帯（`oil`。`TRACK_WEAR` で道床の色からほぼ黒へ 0.70 寄せる）で、さらにラウンド 1 の `wear` 1.8（汚れの色を道床の色から 1.8 倍離す）で黒くなっていた。

## 意味の木（まくらぎ・道床・汚れの枝）

- まくらぎ: 在来線は PC（コンクリート）で灰白色。バラスト軌道の特徴で、スラブ軌道との見分けにもなる → 見えることを残す
- まくらぎの間の砂利: レールの間は、制輪子の粉と油で少し暗くなる。黒くはならない → 油の帯を薄くする
- レールの脇: 鉄粉のさび → 変えていない
