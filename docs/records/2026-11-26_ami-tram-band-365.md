# 作業ログ: 256 で、つながる辺の先が同じ道路でない所を確かめる（#365）

## 目的 / 発端

#354（PR #364）で、256 の平らな道路・路面軌道のタイルは、つながる奥の辺（北・西）の上の 2 行の帯を空け、奥のタイルの絵に任せるようにした（[#354 の記録](2026-11-26_ami-white-line-seam-256.md)）。奥のタイルが同じ道路でない物のときに、帯が埋まらずすき間が出ないかを確かめる。あわせて、#354 で未確認にした路面軌道の 256 の絵と、坂と平らな曲がりの組を見る。

## 分かったこと（事実）

- 前 = #364 の前の `cells.py`、後 = #364 の後（今の main）で、道路・一般道路・路面軌道・道路と路面軌道の車庫・生活道路の踏切の 256 の絵を描き、pak256 の地面に入れてゲームで撮った。
- 草が見えるすき間は、どの組にも無い（前後で草の色に変わった画素を数えて 0）。
- 路面軌道に、#364 で入った継ぎ目があった。
  - 次の 2 つの所で、境の 2 行に、レールを横切る暗い線が出た。前はレールがつながっていた。
    - 土の上の軌道と、道路の上の軌道の境（南北・東西とも）
    - 路面軌道の車庫の前（北・西とも）
  - 道路の上の軌道のタイルは、同じタイルに道路と軌道を重ねて描く。
    - 道路は、その辺でつながらない（道路は手前で終わる）ので、帯を塗る。そのため道路の端の暗い縁を、奥のタイルの上に描く。
    - 軌道は、その辺でつながるので、帯を空ける。そのため道路の端の縁を、レールで描き直す物が無い。
- 道路だけの組は、前後の違いがタイルの境の路面の粒か、線の端の 1〜2px だけだった。
  - 生活道路と一般道路の境（南北・東西）
  - 道路の車庫（北・西）
  - 踏切（道路の北・西）
  - 坂と平らな曲がりの組 5 つ
    - 1 段の台の上の曲がりで、手前が坂の物
    - 1 段の台の上の曲がりで、奥が坂の物
    - 平らな曲がりの手前に上りの坂がある物（南・東）
    - 坂を下りた手前の平らな曲がり
- 見本の道を、台の上の端で地面と違う高さ（z=0）を渡して敷くと、`build_way` は何も返さずに敷かない。台の上の端は z=1 で渡す。1 回目はそれで坂の組に道が無く、撮り直した。今の見本は、敷いた後に道の有無を確かめる。

## 推測・未確認事項

- 道路を変えずに軌道だけ帯を塗ったので、軌道の曲がり・T 字で、#354 の白線と同じ延長の食い違いがレールに出るおそれがあった。道路の上の軌道の曲がり（西と南・北と西）と T 字を撮り、前・今の main・直した後で見分けが付かないことを確かめた。土の上の軌道の曲がりは、今の main と直した後で明るさの大きく違う画素が無いことだけ確かめた（直した後の軌道のシートは前と同じ）。
- 雪の気候は撮っていない。
- 道路と路面軌道のほかの way（運河・歩道）が道路とつながる所は無い。運河・歩道は持ち分を上へ広げる行数が帯より大きく、#364 の分岐を通らない（#354 の記録）。
- 車庫と踏切は、pak256 に AMI のほかの物が無いので、AMI の車庫と、生活道路と在来線（バラスト）の踏切だけを見た。

## 結果どうしたか

- 路面軌道の profile（`addons/ami/blender/render.py`）に `fill_back_band` を足した。`sheetlib.track_sheet` は、この印のある物には持ち分に `exits` を空（`""`）で渡す。帯は #364 の前と同じく塗る。道路は #364 のまま空ける。`cells.py` は注記だけ直した。
- 256 の路面軌道のシートは、#364 の前とバイトで同じになった。128 の路面軌道のシートは、直す前とバイトで同じ（128 の持ち分は `exits` を見ない）。
- 確かめた環境: OTRP v64（`addon_check` の写し）、`flat_512_left_v64`、昼、拡大 3、温暖。地面は pak256 の main を `tools/build.py --no-ami` で組んだ物（道路名の書き換えより前の `tools/game.py` の写しで、保存データの道路名は書き換えていない）。AMI は 256 の、生活道路・一般道路・路面軌道・道路と路面軌道の車庫・生活道路の踏切と、`src256/` にある物を組んで入れた。見本は手元のスクリプト（記録には入れていない。置き方は上の組の説明のとおり）。
  - [見つけた継ぎ目](../../addons/ami/docs/365_tram_band/tram_seam.png)（左から前・今の main・直した後）: 直した後は前と同じくレールがつながる。
  - [軌道の曲がり・T 字](../../addons/ami/docs/365_tram_band/tram_curve.png): 3 つとも見分けが付かない。
  - [問題の無かった組](../../addons/ami/docs/365_tram_band/no_issue.png)（前と後。道路だけなので、後は今の main と直した後で同じ絵）
