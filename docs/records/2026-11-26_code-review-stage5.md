### pak256 の進捗管理に知らせる材料

256 の見た目が直すべきものかは pak256 が決める取り決めなので、ここでは起票の案にしない。直すことになれば、道具は AMI のリポジトリにあるので、取り決め（pak256 の進捗管理が中身を知らせ、AMI で起票して直す。例: #282）のとおり AMI で直す。知らせるかは進捗管理が決める。

- `tiled_concrete_material`（`core.py:207`）は、#298 で直した `noisy_material` と違い、粒（`grain`・`stain_scale`）に `SCALE` を掛けていない（`core.py:261`）。256 で、線路の基盤・高架・転車台・跨座式モノレールのコンクリートの粒が粗くなる見込み（推測。見ていない）。直すなら #298 と同じく関数の中で掛け、128 はバイトで同じになる見込み。
- `check_ground_mask.py` は、pak256 の `54fc440` の地面の決まりの写しを持つ。pak256 の `draw_ground.py` を変えるときは、AMI の側の写しも直す要がある。
