## 目的 / 発端

## 準備

- 見本 `addons/ami/ingame/tram_sample.nut` に `SUFFIX` を足した。`sample.nut` の `wdx` と同じ考え方で、路面軌道（`ami_tram`）の名前にだけ付ける。下敷きの道路（AMI の道路 3 種・`Road_050`）と橋脚（`ami_pier_rail`）は本番の `dist/ami.pak` のまま。`sample_parallel.sh` の置き換え（`local SUFFIX = "";` の行）が効く

  - 確かめ: 設定なしの鍵（`0check`）と、作り直しの道を通して本番と同じ値で描く鍵（`0same`）の両方で、本番の `src/ami_tram.png` と画素で同じだった
- 撮影はどれも `OTRPv64_3.exe`・`flat_512.sve`、検証用のフォルダの写しで起動した（`sample_parallel.sh` は `JOBS=3 BASE_PORT=47150`、`calib_capture.sh` は `PORT=47126`）。見本は 94 画面（温暖・降雪 × 下敷き 5 種 × 区画）
- くどさの測り方: 路面軌道の絵は不透明で、土の上と道路の上で画素が同じだった（ラウンド 0 の区画 B を、土の上と一般道路の上で比べて、路面軌道の画素 30385 のうち違うのは 0）。そのため、くどさは既存の `calib.nut`（土の上）に `WAYS_NUT` で並べて測る。道路の上に敷く見本（`calib_tram.nut`）は作らなかった

## 直す所

ラウンド 0 の画面（`addons/ami/docs/tram_round1_game.png` の上の段、5 倍）では、レールが読めず、灰色の帯に暗い細線が 2 本あるように見えた。シートの縦の切り口（直線のセル）で、頭の画素は 145 前後で床（135〜145）と変わらず、溝の 88〜112 だけが線として見えた。

原因はレールの頭の材質: 色は明るい（0.82）が金属 0.8 で、環境を映して暗く写る。頭の幅も 1px に満たず、外側の目地の暗さと混ざる。

## 葉ごとの試し

| 鍵 | 試し | 判断 |
|---|---|---|
| `1noseam` | 外側の目地を描かない | 採らない。頭の色が変わらないので、見え方はほぼ同じ |
| `1head`・`1headw` | 頭の幅を 0.14・0.17 に | 採らない（単独では）。頭が暗いままで、線の幅だけが変わる |
| `1headg`・`1headgs` | `1headw` + 溝を 0.14 に（目地あり・なし） | 採らない（単独では）。暗い線が太くなるだけ |
| `1dull` | 金属 0 で、今の色（0.82） | 頭が明るく出始める（約 160） |
| `1bright` | 金属 0、在来線の頭の帯の色（0.92, 0.91, 0.88、粗さ 0.4） | 頭が 155〜160 で、まだ溝と混ざる |
| `1brighth` | `1bright` + 頭 0.14・目地なし | 頭 195。溝 105 |
| `1brighthg` | `1brighth` + 溝 0.14 | 採る。頭 195・溝 92〜110・床 135〜145 で、明るい頭と暗い溝の 2 色の線になる（pak128 の `Tram_Track_050_A` の作りと同じ） |
| `1brightw` | `1bright` + 頭 0.17・目地なし | 採らない。頭が太く、縁の帯と見分けにくい |

セルの比べは `addons/ami/docs/tram_round1_cells.png`（上から 本番・`1noseam`・`1headg`・`1bright`・ラウンド 1。直線・曲線・T字・十字、4 倍、道路の色の上）。

## 評価（ラウンド 0 → 1）

| 観点 | 結果 |
|---|---|
| ① 欠陥 | 同じ。シートの輪郭（透過の範囲）の差は 0px。ゲームの画面の差は路面軌道の画素の中だけ（94 画面）。`sheet_audit.py` の候補は前と同じ 24（T字の穴。ラウンド 2 で直した） |
| ② 写実 | 良くなった。レールの頭と溝が 2 色の線として読める（`tram_round1_game.png`、上がラウンド 0、下が 1。十字と T字） |
| ③ くどさ | 線を除いて、細かさ 0.0450 → 0.0470、孤立点 6.84 → 9.16。構造の線の割合は 14.0% → 32.2%（レールが線として数えられた）。線を除かない孤立点は 91.6 → 50.6 に減った（頭と溝が混ざった点が、まとまった線になった） |
| ④ そろい | 直線・曲線・分岐・十字・行き止まりで同じ作り。雪の絵は夏と同じ（決まりどおり） |

- くどさの判定: 細かさは在来線の物差しで「物足りない」の側（0.058 未満）、孤立点は「許容」（5.9〜32）で、合わせて「許容」。ただし物差しは在来線の温暖の絵で合わせたもので、路面軌道には当てはめを確かめていない（判断できない点）
- 手本の `Tram_Track_050_A` は細いレールだけの絵で、土の上に敷くと way の画素が縁を削って残らない。道路の上に重ねて測る道具が無いので、手本の幅は測っていない

## 分かったこと

- 金属の材質（金属 0.8）は、この描き方では環境を映して暗く写り、明るい色にしても明るく出ない。1px ほどの明るい線は金属 0 で描く（在来線のラウンド 2・3 の頭の帯も金属 0）
- 1px に満たない部品は、幅を変えるより先に、隣り合う部品との明暗の差を見る（目地を消しても頭の幅を変えても、頭が暗いままでは見え方が変わらなかった）
