# SIS の高速道路の合流・分岐パーツの分析（#167）

対象: `refs/sis/road/Expressway/` の `2to2-1`・`2to2-1R`・`2to2-2`・`3to3-1`。画像は `SIS_Expwy_Tram_G_*.png`（256 画素のセルを 5 列 × 8 行）。SIS は CC BY-NC-SA 4.0 なので、画像・dat は AMI に入れない。ここに書くのは構造の読みだけ。

## 作り（dat）

- どれも `obj=way`、`waytype=tram_track`、`system_type=0`、`draw_as_ding=1`。道路のタイルに路面軌道として重なり、物として描かれる（道路は残る）。AMI の #156（交差点の路面表示、ADR 0011）と同じ作り。
- 各パーツは向きごとに 2 本（例: `2to2-1` と `2-1to2`）。`2to2-1R` は左右を反転した版。
- セルの割り当て: `.1.x` = 端 W/N/E/S、`.2.x` = 斜め、`.3.0/.3.1` = EW/NS の直線、`.3.2` = 孤立、`.3.3` = 十字、`.4.x`・`.5.x` = 坂、`.6.x` = 端の NE/SE/NW/SW、`.7.x` = T字 NSE/NSW/SEW/NEW。

## 画素で読んだこと（2to2-1。暗い背景に重ね、5 倍で拡大して読んだ）

- 直線のセル（`.3.0`・`.3.1`）の路面の面積は、孤立のセル（`.3.2`、全面 4096 画素）の約 46%（暗い画素 1554 + 白い画素 220〜338）。つまり半幅の帯で、内側の縁に点線、外側の縁に側壁と実線。SIS では 1 車線が半タイル、2 車線が 1 タイル。
- 十字のセル（`.3.3`）は全面の約 89% で、向かい合う 2 辺のそれぞれ別の側にゼブラ。
- T字のセル（`.7.x`）は全面の路面で、中央線は破線（2 本）、片側の縁は実線＋側壁、反対側の縁は点線で、その側のタイルの端にゼブラ（斜線の梯子形）。ゼブラは同じタイルの片端に付く。
- 端のセル（`.6.x`）は、狭い側の端では路面が側壁（曲がる縁石）に寄り、広い側の端に向けて中央線が曲がって車線が横へずれ、広がった側の縁にゼブラの斜線（扇形）が付く。路面の面積は全面の約 28〜30%。
- 2-1R は 2-1 の左右反転（ゼブラと側壁の側が逆）。3to3-1 は車線の線が 3 本（破線 2 本）で、ゼブラが同じく広がる側の縁に付く。

## 読み切れていないこと

- 1 タイルのうち、ゼブラが占める幅と長さの比。
- 中央線が曲がる位置（タイルのどこから動き始めるか）。
