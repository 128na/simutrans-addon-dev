# 調査/作業ログ: Boolean の `use_self` を外して速くする試し

（2026-11-17。[シート描画の速度改善](2026-11-17_sheet-render-speed.md)の続き。対象は `track_wall_back` と blender-poc の 28 枚・AMI）

## 目的 / 発端

案 2 の後も、時間の約 9 割は Boolean だった。その大半は分岐の通り道を削る処理で、`use_self=True` が遅さの一因と見て、外す方法を探した。

## 分かったこと（事実）

### 重い Boolean の所在

`track_wall_back` の通り道の切り抜き（この 1 枚の内訳）:

| 条件 | 回数 | 時間 |
|---|---|---|
| 経路 6 本のタイル | 72 回 | 80.6 秒 |
| 経路 3 本のタイル | 144 回 | 20.4 秒 |
| そのほかの Boolean | 82 回 | 2.2 秒 |

この 1 枚に経路 2 本のタイルは無く、「重ならないタイルだけ `use_self` を外す」案は対象が無かった。

### 試した方式（`track_wall_back`、基準は `src/` の画像）

| 方式 | 時間 | 基準との差 |
|---|---|---|
| 基準（`use_self` あり、帯をまとめて削る） | 117 秒 | － |
| `noself`（`use_self` を外すだけ） | 31 秒 | 透明の範囲 43,548 画素、色 26,144 画素（240 セル中 40 セル） |
| `seq_self`（帯を 1 本ずつ削る、`use_self` あり） | 54 秒 | 差なし |
| **`seq`（帯を 1 本ずつ削る、`use_self` なし）** | **27.5 秒** | **差なし** |
| `manifold`（Manifold ソルバー） | 400 秒でも終わらず | 比較できず |

- `noself` の絵: 分岐・十字のタイルで、通り道の中の壁が削られずに残り、曲線の壁の帯がタイルの上を何本も横切る。重なり合う帯を 1 つの形として削ると、`use_self` なしでは重なりを処理できない
- `seq`: 帯 1 本は自分と重ならないので `use_self` が要らず、形も小さくなる。`seq_self` の差（117 → 54 秒）が形を小さくした効果、`seq` の差（54 → 27.5 秒）が `use_self` を外した効果

### 採用と確認

- `seq` を採用した（`assemble._place` が他の経路の帯を 1 本ずつ `boolean(..., use_self=False)` で削る。`core.boolean` に `use_self` 引数を足した）
- blender-poc の全 28 枚（16 並列）と AMI のシートを描き直して `src/` の差分なし（前と全画素同じ）。全体の時間は 287 秒 → 181 秒
- 帯の太さ（`j < i` は太い帯、それ以外は細い帯）と削る順（経路の番号順）は前のまま

## 決まり / 運用

- `use_self` は、削る形（や削られる形）が自分自身と重なるときに要る。重ならないと分かる形は `False` にできる
- Boolean を足すときは、削る形が自己交差しないよう 1 つずつに分けられないかを先に考える

## 未解決 / 次にやること

- Manifold ソルバーは、このシートでは終わらなかった（入力が閉じた多様体でないためと見られるが、原因は未確認）
- `use_self=True` の Boolean（`half` の INTERSECT など）が残っている。時間への影響は小さい（そのほかの Boolean 82 回で 2.2 秒）
- 全体の残りは、帯 1 本あたりの Exact の演算
